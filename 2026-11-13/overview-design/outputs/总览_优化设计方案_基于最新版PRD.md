- **依据文档：**《Adam Bot_总览_V1.0_PRD_最新版》（2026-11-13 最新确认版）

## 0. 结论摘要

1. **最影响演示结论的是统计口径**：当前 demo 的会话数包含处理中会话，转人工率分母是全会话，AI 解决率分母是已结束会话；新 PRD 统一为「只统计已结束正式会话」，且 `N = V + I`、`V = S + U + H`，两项比率都除以 `V`。不先改这一层，卡片、趋势、对比数字都会讲错。
2. **会话数卡需要增加二级信息**：主值 `N`，卡内追加「有效会话 V / 无效会话 I」，不新增卡片、不做环比、不做趋势。
3. **趋势区入口从「跳收件箱」改为「打开会话记录弹窗」**：单选下拉切换三项指标，下拉左侧常驻「查看会话记录」按钮（三个指标下都显示），点击打开统一的只读会话记录弹窗；弹窗按当前趋势指标预置分类。
4. **会话记录弹窗是本期新增的最大界面模块**：大尺寸弹窗 + 顶部五类筛选 + 左侧收件箱式列表（新增结果标签）+ 右侧只读聊天。它取代了旧方案里「查看已解决会话 → 跳收件箱」的链路。
5. **增量改造而非重写**：现有趋势图组件已具备按小时/天/周/月分桶、空值断线、悬停「时间＋当前指标值」、暂无数据/暂无可计算数据、骨架与渐变曲线，可直接沿用；涨跌胶囊样式与正负语义也符合新 PRD，不需要动。
6. **有 5 处与用户此前已确认取舍冲突**：菜单位置、收件箱「已解决」口径、国际化、权限演示、弹窗工作量，均在文末单列，等待裁决。

## 1. 当前 demo 与新 PRD 的差异总览

| 区域 | 当前 demo（回退后） | 新 PRD 要求 | 影响 |
|---|---|---|---|
| 统计范围 | `n` 统计全部创建会话（含处理中） | 只统计**已结束**的正式会话（1.2.1 / 1.3.1） | 直接改变所有数字与结论 |
| 会话分类 | 无有效/无效拆分 | `N=V+I`；无效不参与比率（1.2.2） | 卡片、趋势、弹窗都要分类 |
| AI 解决率 | `R ÷ E`（已结束，转人工已排除） | `S ÷ V`（1.3.2） | 分母变化，数值变化 |
| 转人工率 | `T ÷ N`（全部创建会话） | `H ÷ V`（1.3.2） | 分母变化，数值变化 |
| 会话数卡 | 只有主值＋环比＋对比上期 | 追加「有效会话 / 无效会话」一行（1.3.2 / 1.3.3） | 卡片信息层级变化 |
| 趋势指标切换 | 三按钮 Radio.Group | 单选下拉 Select，默认会话数（1.5.1） | 控件形态变化 |
| 趋势入口按钮 | 无 | 下拉左侧常驻「查看会话记录」（1.5.1 / AT-25） | 新增入口 |
| 查看明细 | 无（旧方案为跳收件箱） | 打开统一「会话记录」弹窗，不跳转（1.6 / AT-26） | 新增最大模块 |
| 趋势粒度 | 今天按小时；≤30 天按天；≤90 天按周；>90 天按月 | 同左（1.5.2） | 已满足，无需改 |
| 趋势断点 | 比率为 null 时断线，悬停显示「暂无可计算数据」 | 同左（1.5.2） | 已满足，保留 |
| 筛选状态 | 不写入 URL，刷新/后退丢失 | PRD 未要求 URL；仅要求弹窗关闭后保留总览状态（1.6.7） | 可选增强，不作为验收项 |
| 删除对象 | 选中项被删后仍保留失效值 | 仅重置该项为「全部」（1.1.2） | 需要补 |
| 无数据 / 失败 | 已有基础处理 | 需要 `N=0`、`V=0`、失败不冒充 0（1.7） | 需要补边界 |

## 2. 优化项清单（按影响程度排序）

### P0-1 统计口径重构（会改变演示结论）

**需求要点（1.2、1.3、1.4）**

- 只统计当前租户正式渠道、**已经结束**的 Conversation；处理中、预览测试会话不计入。
- 有效会话 `V` 再按互斥结果拆成 `S`（已解决）、`U`（未解决）、`H`（转人工），满足 `V = S + U + H`；转人工优先于已解决。
- 无效会话 `I` 不参与任何分子、分母。
- 上期对比与趋势分桶全部使用同一口径；趋势每个桶用桶内 `S/V`、`H/V` 重算，不能对每日百分比求平均。

**落地方案**

- 会话模型增加两个演示字段：`valid`（有效/无效）与 `outcome`（`resolved | unresolved | handoff | null`）。无效会话 `outcome = null`。
- 汇总：`n` 只累计 `ended`；`v` 累计 `ended && valid`；`i` 累计 `ended && !valid`；`s/u/h` 只从有效会话中按互斥结果累计。
- 上期对比：会话数用相对增长率；两项比率用百分点差；`V=0` 时对比值显示 `—`。
- 趋势分桶：每桶独立累计 `n/v/s/u/h`，比率为 `null` 时不绘制数据点并断开曲线。
- 演示数据：无效会话约占已结束会话 10%–15%；转人工/AI 解决只生成在「已结束且有效」的会话上；保持每对象近 7 天 ≥15 场、今天每整点 ≥3 场的覆盖，避免筛选后空图。
- **数据自检（演示前必看）**：`N=V+I`、`V=S+U+H`、`S/U/H` 互斥、任一 `V=0` 时比率为 `—`。

**涉及位置**：`src/overview/analytics.ts`、`src/overview/mockData.ts`、`src/pages/OverviewPage.tsx`、`src/components/OverviewTrendChart.tsx`（仅字段名适配）。

**验收映射**：AT-02、AT-04～AT-12、AT-24、AT-43。

### P0-2 会话数卡补「有效会话 / 无效会话」（改变卡片读数方式）

**需求要点（1.3.2 / 1.3.3 / AT-15）**

- 不新增卡片；在会话数卡内展示 `有效会话 V`、`无效会话 I`。
- 两者为整数、千分位、无单位、不做环比、不进趋势。
- 三张卡统一层级：指标名称 → 当前值＋涨跌标签 → 对比上期数值；会话数卡在「当前值」与「对比上期」之间插入细分行。

**落地方案**

- 卡片结构：

```text
会话数  (?)                     AI 解决率  (?)            转人工率  (?)
1,286   [↑ 12.4%]               70.0%     [↑ 10.0 p.p.]   18.2%   [↓ 3.8 p.p.]
有效会话 1,102 · 无效会话 184      对比上期 60.0%              对比上期 22.0%
对比上期 1,144
```

- 细分行用弱化文本（`--color-muted-foreground`），数值用正文色＋等宽数字；窄屏允许换行。
- 骨架态：会话数卡比其他两卡多一条细分行占位；失败态沿用现有「整块错误＋重试」结构，不单独造占位。
- 三张卡保持只读，不添加点击/下钻（1.3.2）。

**涉及位置**：`src/pages/OverviewPage.tsx`、`src/styles/global.css`（新增细分行样式）。

**验收映射**：AT-15。

### P0-3 趋势区改为「左侧按钮 + 右侧单选下拉」（改变操作路径）

**需求要点（1.5.1 / AT-22 / AT-25 / AT-26）**

- 仅一张折线图；下拉选项顺序固定为「会话数、AI 解决率、转人工率」，默认会话数。
- 「查看会话记录」按钮**始终显示**在下拉左侧，不随指标隐藏；点击打开同一个弹窗，不跳转收件箱。
- 打开弹窗不改变趋势已选指标；卡片不参与跳转。

**落地方案**

- 趋势区头部右侧改为一个操作组：`[查看会话记录]  [会话数 ▾]`，右对齐；下拉宽约 132px，按钮用次级文字按钮，避免抢主按钮视觉。
- 按钮点击只做一件事：按「当前筛选＋当前趋势指标」打开会话记录弹窗；不修改 URL、不导航。
- 旧的「仅在 AI 解决率显示按钮并跳收件箱」方案作废（与新 PRD 冲突，见第 9 节 C5）。

**涉及位置**：`src/pages/OverviewPage.tsx`、`src/styles/global.css`。

**验收映射**：AT-22、AT-25、AT-26、AT-39。

### P0-4 新增「会话记录」弹窗（本期最大新增）

**需求要点（1.6 全节）**

- 大尺寸弹窗，标题「会话记录」；顶部筛选（时间、AI Agent、渠道、会话类型、处理结果）；左侧列表复用收件箱样式并新增结果标签；右侧只读聊天。
- 弹窗意图：统一明细入口，不跳转、不加路由、不改收件箱结构。
- 默认分类随趋势指标：会话数→全部/全部；AI 解决率→有效/已解决；转人工率→有效/转人工。
- 「会话类型＝无效」时处理结果重置为「全部」并禁用；从无效切回全部/有效后恢复可选、默认全部。
- 修改弹窗筛选只影响弹窗，不回写总览；关闭后再次打开按当前总览条件＋当前趋势指标重新初始化。

**落地方案**

- 弹窗尺寸：宽 `min(1120px, 92vw)`、高 `min(760px, 86vh)`；顶部标题栏 + 一行筛选 + 两栏内容；遮罩沿用现有 Modal 规范。
- 左侧列表宽约 360–400px，复用 `.inbox-*` 列表样式与选中态；行内新增结果标签：
  - 已解决：绿色系（成功色浅底）；
  - 未解决：中性灰；
  - 转人工：橙色系（警示色浅底）；
  - 无效：灰色描边标签。
- 右侧复用收件箱聊天详情视觉（气泡、头像、时间、图片、系统消息），**只读**：不显示输入框、发送、转接、结束会话等操作。
- 列表排序沿用「最近更新时间倒序」；无记录时左侧显示「暂无会话记录」，右侧显示未选中空状态。
- 加载中：列表骨架行 + 右侧骨架；失败：列表区错误提示＋重试，不得显示成空态。
- 会话类型/处理结果的组合逻辑按 1.6.4 实现；「全部＋某结果」只返回有效会话；无效＋任何结果不可组合。
- 弹窗内切换筛选或选择会话只更新弹窗内部状态；关闭即销毁临时筛选，不写回总览。

**演示数据策略**

- 弹窗列表与总览统计共用同一份会话数据，避免「卡片 1,286、弹窗只有 81 条」的割裂。
- 列表行需要：客户名、渠道图标＋名称、最新消息摘要、最近更新时间、会话类型、处理结果；聊天内容可按会话 id 用 3–4 套模板确定性生成，选中时再渲染，避免一次性生成大量消息。
- 时间筛选沿用创建时间；已结束才展示；列表中的「已解决」必须不含转人工。

**涉及位置**：建议新增 `src/components/OverviewRecordsModal.tsx`（或 `src/pages/overview/…`），复用 `src/pages/InboxPage.tsx` 的展示结构与 `src/styles/global.css` 的 `.inbox-*` 样式；数据侧扩展 `src/overview/mockData.ts`。

**验收映射**：AT-26～AT-39。

### P1-2 趋势粒度、断点与悬停（多为沿用）

**需求要点（1.5.2）**

- 今天按小时；近 7/30 天按天；自定义 ≤30 天按天、31–90 天按周（周一起）、>90 天按月。
- 范围边界只统计所选时间段内的数据。
- 每桶用 `N / S÷V / H÷V`；悬停只展示「时间＋当前指标值」。
- `N=0` 的桶会话数为 0；`V=0` 的桶比率为空、断线、悬停「暂无可计算数据」；全范围 `N=0` 显示「暂无数据」；`N>0` 但所有桶 `V=0` 显示「暂无可计算数据」。

**落地方案**

- 现有分桶规则与边界裁剪已符合，保留；只把汇总字段换成新口径。
- 现有曲线已支持空值断线、悬停时间＋值、渐变面积、实时点、轴标签抽稀，全部沿用。
- 不新增「点击桶下钻」「多指标叠加」「图例」，PRD 明确一张图、单指标。

**涉及位置**：`src/overview/analytics.ts`、`src/components/OverviewTrendChart.tsx`。

**验收映射**：AT-23、AT-24。

### P2-1 状态与细节

- **首屏加载**：保留三卡与趋势布局，显示骨架；不展示 0。
- **手动刷新**：保留当前筛选、指标和旧数据，按钮进入 loading；成功后整体更新。
- **无数据**：`N=0` 时会话数、有效、无效均显示 `0`，两项比率 `—`，趋势「暂无数据」。
- **`V=0` 但 `N>0`**：正常显示 `N` 与无效数，两项比率 `—`。
- **失败**：有成功数据时显示顶部错误条并保留旧数据；无成功数据时显示错误态＋重试，不能用 0 或「暂无数据」冒充。
- **筛选无结果**：保留筛选条件，按 `N=0` 空态显示。
- **对象删除**：只重置该项，保留其他筛选（见 P1-1）。
- **卡片脚注**：允许换行，不单行截断；窄屏下三卡纵向堆叠，细分行不溢出。
- **日期范围**：结束早于开始或选择未来日期时给出明确提示，不静默纠正（PRD 1.1.1）。

**层级原则**

- 筛选是全局条件，只作用一次，卡片、细分、对比、趋势、弹窗初始值全部共享。
- 卡片只读数，不承担导航；唯一明细入口在趋势区，避免两个入口口径不一致。
- 趋势区头部一行只放「标题 + 操作组」，操作组右对齐，按钮与下拉同一基线。
- 会话数卡的细分行是第三层级信息，视觉弱于主值和涨跌，强于脚注。

## 4. 指标口径如何落到界面

### 4.1 公式与分母

| 界面 | 公式 | 分母 | 不计入 |
|---|---|---|---|
| 会话数 `N` | 已结束正式会话数 | — | 处理中、预览测试、非正式渠道 |
| 会话数卡细分 | `V`、`I`，且 `N=V+I` | — | 同上 |
| AI 解决率 | `S ÷ V × 100%` | 有效已结束会话 | 无效会话、转人工会话（转人工优先） |
| 转人工率 | `H ÷ V × 100%` | 有效已结束会话 | 无效会话 |
| 对比上期 | 同公式，仅平移日期 | 同上期口径 | 同上 |

### 4.2 展示格式

- 会话数：整数＋千分位，无「场」「个」量词，如 `1,286`。
- 有效/无效：整数＋千分位，无单位。
- 比率：保留 1 位小数；`V=0` 显示 `—`（不是 `0%`）；`V>0` 且分子为 0 显示 `0.0%`。
- 涨跌：会话数用 `%`（相对增长），比率用 `p.p.`（百分点）；保留 1 位小数；无变化显示 `0.0%` / `0.0 p.p.` 且不带箭头。
- 会话数涨跌为中性色；AI 解决率上升、转人工率下降为积极色，反向为消极色；箭头与数字必须同时存在。
- 脚注统一 `对比上期 {上期值}`；上期 N=0 且本期>0 显示「新增」；两期 N=0 显示 `—`；任一期 V=0 的比率变化显示 `—`。

### 4.3 空值与边界

| 场景 | 卡片 | 趋势 |
|---|---|---|
| `N=0` | `0 / 0 / 0`，两比率 `—` | 「暂无数据」 |
| `N>0, V=0` | `N`、`I` 正常，两比率 `—` | 会话数正常；比率图「暂无可计算数据」 |
| `V>0, S=0/H=0` | 对应比率 `0.0%` | 对应桶显示 0.0%，不断线 |
| 请求失败 | 错误态/保留旧数据 | 错误态，不显示 0 |

## 5. 趋势图交互方案

| 项目 | 方案 |
|---|---|
| 指标选择 | 单选下拉（非按钮组），顺序：会话数 / AI 解决率 / 转人工率，默认会话数；切换即重算当前图 |
| 明细入口 | 下拉左侧常驻「查看会话记录」按钮；点击打开弹窗，按当前指标预置分类；不跳收件箱 |
| 粒度 | 今天=小时；7/30 天=天；自定义 ≤30 天=天、31–90 天=周（周一起）、>90 天=月；边界桶裁剪到所选区间 |
| 分桶计算 | 桶内重新求 `N`、`S/V`、`H/V`，不平均百分比 |
| 断点 | `V=0` 的桶不绘制点、不跨点连线；`N=0` 的会话数桶画 0 |
| 悬停 | 只显示「时间 + 当前指标值」；空值显示「暂无可计算数据」；不展示分子分母或其他指标 |
| 空态 | 全范围 `N=0` → 「暂无数据」；`N>0` 但比率全为空 → 「暂无可计算数据」 |
| 返回恢复 | 弹窗关闭回到总览，保留时间、Agent、渠道、指标；再次打开按当前状态重新初始化弹窗筛选 |
| 收件箱关系 | 新 PRD 已取消「跳收件箱」；不再需要 URL 携带筛选回传。若后续希望刷新/后退也保留总览筛选，可另做 URL 同步增强，但不作为本期验收项 |

## 6. 「会话记录」弹窗设计

### 6.1 布局

```text
┌ 会话记录 ─────────────────────────────────────────────── × ┐
│ [时间范围] [AI Agent ▾] [渠道 ▾] [会话类型 ▾] [处理结果 ▾] │
├──────────────────────┬────────────────────────────────────┤
│ 会话列表（360–400px） │ 聊天详情（只读，复用收件箱样式）    │
│ ○ 客户A  [已解决]     │  客户消息 / AI 消息 / 图片 / 系统消息│
│ ○ 客户B  [转人工]     │                                    │
│ ○ 客户C  [无效]       │                                    │
│ …                    │                                    │
└──────────────────────┴────────────────────────────────────┘
```

- 标题栏固定；筛选行固定；内容区左右独立滚动。
- 列表项：头像、客户名、渠道图标＋名称、最新消息摘要（单行省略）、更新时间、结果标签；选中态沿用收件箱。
- 右侧：消息气泡、时间、图片、系统消息；无输入框与任何操作按钮。

### 6.2 初始分类（由趋势指标决定）

| 趋势当前指标 | 会话类型 | 处理结果 | 列表首批 |
|---|---|---|---|
| 会话数 | 全部 | 全部 | 全部已结束（有效＋无效） |
| AI 解决率 | 有效 | 已解决 | `outcome=resolved` |
| 转人工率 | 有效 | 转人工 | `outcome=handoff` |

### 6.3 组合规则

- 类型=全部 + 结果=全部：有效与无效都展示。
- 类型=全部 + 结果=已解决/未解决/转人工：只返回有效会话。
- 类型=有效 + 结果=全部：全部有效会话。
- 类型=有效 + 结果=具体：对应互斥结果。
- 类型=无效：结果强制「全部」并禁用；切回全部/有效后结果恢复可选、默认全部。

### 6.4 状态

| 场景 | 左侧 | 右侧 |
|---|---|---|
| 加载中 | 列表骨架 | 聊天骨架 |
| 无匹配记录 | 「暂无会话记录」 | 未选中空状态 |
| 加载失败 | 错误提示＋重试 | 保持空或上次选中状态 |
| 切换筛选 | 列表刷新，自动选中首条或清空选中 | 同步更新 |
| 点击其他会话 | 保持列表 | 仅切换聊天内容，不改变任何状态 |
| 关闭/再次打开 | 销毁临时筛选 | 按总览当前条件重新初始化 |
