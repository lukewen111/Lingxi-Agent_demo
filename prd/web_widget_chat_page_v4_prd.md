# IM项目新增【网站小部件／聊天页面】渠道功能需求文档

# 1．产品原型

进入当前项目【渠道】，查看【全部】【网站小部件】【聊天页面】。

页面与交互以高保真原型为基础，业务规则包含本轮确认补充的内容；原型尚未实现的已确认规则同样属于本需求。本文只涉及两种新增渠道，不调整 Livechat、Telegram，不新增统计页面。

# 2．功能需求描述

**统一校验口径：**文本长度按用户可见字符计算，中英文、数字、标点和单个表情均计为 1 个字符；单行字段不接受换行。渠道名称和域名保存前去除首尾空格；品牌名称、签名等非必填字段仅含空格时按空值处理。超出上限、格式错误或必填缺失时，在对应字段附近提示原因并阻止提交，不静默截断已输入内容。

## 2.1 全部

**功能定义：**查看渠道类型，创建连接或进入对应类型的渠道管理。

### 2.1.1 渠道卡片

| 字段 | 定义与交互 |
|---|---|
| 图标、名称、说明 | 网站小部件用于网站内悬浮咨询；聊天页面用于独立链接咨询 |
| 已连接数量 | 有实例时展示「已连接 N」，包含启用和停用实例；不表示实际安装成功数量 |
| 添加／管理 | 无实例时，网站小部件显示「添加网站」，聊天页面显示「添加新连接」；有实例时显示「管理」，进入对应列表 |

一个渠道绑定一个接待 AI Agent，同一个 Agent 可被多个渠道绑定。

## 2.2 网站小部件

**功能定义：**创建网站渠道、配置品牌和展示规则，通过安装代码在网站内提供聊天入口。

### 2.2.1 渠道列表

| 模块 | 字段 | 功能与交互 |
|---|---|---|
| 搜索栏 | 搜索 | 最多输入 50 个字符；按渠道名称模糊搜索，忽略首尾空格和大小写；清空恢复全部 |
| 新建入口 | 添加网站 | 打开新增渠道弹窗 |
| 列表 | 渠道名称 | 左侧展示类型图标，右侧第一行展示名称、第二行展示已保存的网站域名及访问图标；图标与右侧两行信息横向排列，并相对右侧信息整体垂直居中；名称点击进入详情，默认打开基本设置；访问图标在新标签页打开 HTTPS 网站，长域名省略并可悬停查看完整内容，无域名时隐藏第二行 |
| 列表 | 接待 AI Agent | 展示头像和名称；关联对象不存在时显示「未配置」 |
| 列表 | 创建时间 | 精确到分钟，编辑配置不改变创建时间 |
| 列表 | 状态 | 未连接／已连接；收到实际网站加载当前渠道代码的有效回执后标为已连接，只代表曾成功连接，不代表实时在线或全站安装 |
| 列表 | 启用状态 | 开关，即时生效；启用时检查已保存的 Agent 是否已发布且正在接待，不满足时阻止并提示 |
| 列表 | 更多操作 | 编辑：进入详情；删除：仅停用渠道可操作 |
| 列表 | 排序与分页 | 创建时间倒序，每页 20 条 |
| 空状态 | 无渠道／无搜索结果 | 无渠道时提供创建入口；搜索无结果时保留搜索框，支持修改或清空 |

**停用与删除：**

- 停用前二次确认；确认后停止客户发送和后续 AI 输出，已发送内容和历史保留，不直接改变会话结果。
- 删除时要求输入与原渠道名称完全一致的内容，匹配后才可确认；删除后列表及数量更新，原代码不再提供服务，历史会话及其归属保留。
- 渠道启用、网站已连接和 Agent 可接待是独立条件，不以其中一个状态代替其他状态。
- 列表加载失败保留查询条件并提供重试，不清空已经展示的数据。

### 2.2.2 新增渠道

弹窗标题为「接入 网站小部件」，类型由入口确定，创建前后均不可修改。

| 字段 | 必填／默认值 | 功能说明 |
|---|---|---|
| 渠道名称 | 是／空 | 1～50 个字符；去除首尾空格后不可为空；全部渠道类型内不可重名，比较时忽略大小写；创建、编辑使用同一规则 |
| 网站域名 | 是／空 | 记录主要网站；完整域名最多 253 个字符，单段最多 63 个字符；支持将 `https://www.example.com/` 转为 `www.example.com` |
| 界面语言 | 是／自动 | 自动、简体中文、繁体中文、英语、越南语、泰语、高棉语、缅甸语、老挝语；只控制界面文案，不改变 AI 回复语言配置 |
| 接待 AI Agent | 是／未选择 | 单选，仅展示已发布的 Agent，不要求正在接待；显示头像和名称，提交时再次校验是否仍有效且已发布 |
| 添加网站 | 主操作 | 校验通过后创建；提交中显示加载并防止重复提交，失败保留输入 |
| 取消／关闭 | — | 有未保存输入时确认放弃或继续编辑，未修改时直接退出 |

**域名校验：**接受普通域名或 HTTPS 根地址，规范化为小写域名，去除首尾空格及末尾域名点；完整域名最多 253 个字符，每个以 `.` 分隔的域名段最多 63 个字符；拒绝 HTTP、IP、通配符、端口、账号信息、查询参数、片段及非根路径。空值、超长或格式非法时提示具体原因并阻止提交。

**创建结果：**

- Agent 正在接待时默认启用，未接待时默认停用；无已发布 Agent 时不能完成创建。
- 初始连接状态为未连接，允许域名为空；生成独立安装代码并打开「安装网站小部件」弹窗。
- 关闭结果弹窗后回到列表，不自动进入详情，不撤销已创建渠道。

### 2.2.3 渠道详情

**功能定义：**配置基本设置、品牌外观、可见性与位置，右侧持续展示预览。

#### 顶部操作栏与保存

| 字段／操作 | 功能与交互 |
|---|---|
| 返回 | 返回渠道列表，有未保存修改时确认放弃或继续编辑 |
| 渠道名称 | 展示当前配置名称 |
| 安装代码 | 打开安装代码弹窗 |
| 已启用／已停用 | 即时生效，与分组保存独立；启用检查已保存的 Agent，不能以未保存草稿代替；停用需确认 |
| 保存 | 仅保存当前分组，成功后清除该组标记，其他组草稿保留；失败保留输入并允许重试 |
| 取消 | 有修改时确认是否放弃当前组修改；确认后恢复该组最近保存值，其他组不变 |
| 未保存标记 | 修改后的导航项显示圆点；切换组保留草稿，不弹离开确认 |

未修改时保存和取消不可用。关闭、返回、切换其他页面或刷新时，有未保存修改均需确认；浏览器关闭和刷新可使用浏览器离开提醒。多人修改发生冲突时提示刷新确认，不静默覆盖。

预览使用当前草稿，客户使用已保存配置。新打开或刷新客户页面时应用最新普通配置，不因外观更新强制重置已打开窗口；停用与撤销授权立即生效。

#### 基本设置

| 字段 | 功能说明 |
|---|---|
| 渠道名称 | 必填，1～50 个字符，其他校验同创建；不改变标识、安装代码或历史归属 |
| 网站域名 | 必填，校验同创建；仅为主要网站标识，修改不自动增删允许域名 |
| 界面语言 | 选项同创建；自动时按网站语言、浏览器语言、英语依次匹配，不支持的语言继续回退；固定语言不执行自动识别 |
| 接待 AI Agent | 仅可选择已发布 Agent，允许尚未接待的对象；更换只对新会话生效，已有会话保留原 Agent；网站小部件和聊天页面均不在字段下展示该规则的常驻提示文案 |

#### 品牌外观

| 字段 | 必填／默认值 | 功能说明 |
|---|---|---|
| 品牌名称 | 否／空 | 最多 50 个字符；空时以渠道名称作占位和客户展示兜底；手动填写后独立维护 |
| 签名 | 否／有问题？我们随时为您提供帮助。 | 最多 50 个字符；显示在品牌名称下方；清空则隐藏，不表示实时在线状态 |
| 品牌 LOGO | 否／文字占位 | 点击图片区域上传或更换，已有图片可删除；仅支持 JPG、JPEG、PNG、WEBP，文件名最多 255 个字符，单文件最大 2 MB，图片宽高均为 16～4096px；不支持动图；格式、大小、尺寸非法或读取失败时保留原配置并提示 |
| 主题色 | 默认 `#1c1f26` | 颜色选择器与 HEX 输入编辑同一值；仅接受 `#` 加六位十六进制字符 |

修改立即更新预览，保存后对外生效。主题色用于品牌头部、客户消息气泡、发送按钮及悬浮入口，不覆盖 AI 气泡和错误等语义状态色。自动选择清晰的前景色，不改变管理员保存的主题色；普通文字对比度不低于 4.5:1，重要交互图标不低于 3:1。

#### 可见性与位置

| 字段 | 默认值 | 功能与交互 |
|---|---|---|
| 允许域名 | 空 | 空表示不限域名，不自动带入网站域名；最多添加 50 个，单个格式及长度校验同网站域名；输入后按 Enter 添加标签，支持逐项移除，重复不添加 |
| 悬浮按钮图标 | 默认消息图标 | 三种预设图标或自定义图片，单选；自定义图片的格式、文件名、大小、尺寸及失败处理同品牌 LOGO，按比例裁切铺满圆形入口 |
| 恢复默认图标 | 自定义时展示 | 清除自定义图片，恢复默认消息图标 |
| 设备 | 桌面端 | 桌面端／移动端，切换后编辑对应设备并同步预览 |
| 展示 | 两端均开启 | 分别控制入口是否显示，不改变渠道启用状态 |
| 按钮位置 | 两端均为右侧 | 左下角／右下角，分别保存 |
| 侧边距／底部间距 | 两端均为 24px | 0～100 的整数，空值、负数、小数及超限不可保存；两端互不覆盖 |

**域名授权规则：**

- 主域名与 `www` 等价，例如 `example.com` 同时允许 `www.example.com`；`shop.example.com` 等其他子域和其他主域必须分别添加，不自动包含所有下级域名。
- 移除最后一项并保存前确认「所有网站均可使用该渠道代码」；取消不生效，确认后恢复不限域名。不限展示域名不等于共享客户历史。
- 保存后仍有允许域名时，失去授权的网站立即停止客户发送、AI 推送和历史读取，提示「当前网站未获授权，无法使用客服」；不直接关闭或转移会话。
- 重新授权并通过来源及身份验证后，可恢复尚未超时会话，不补发取消的回复。来源必须可信，不以客户自报域名作为授权依据。

**设备规则：**视口小于 768px 使用移动端配置，否则使用桌面端。两端均隐藏时允许保存并提示客户将看不到小部件；不删除或结束既有会话。入口避开刘海及底部手势区，适配不改写保存的边距。

#### 预览

**功能定义：**查看草稿外观和消息展示效果，不自动生成 AI 回复，不生成正式会话或写入收件箱。

| 模块 | 功能与交互 |
|---|---|
| 品牌头部 | 跟随品牌、签名、LOGO 和主题色草稿；通知图标可切换预览静音 |
| 初始消息 | 一条客服消息、一条客户消息，按选择语言展示预置内容 |
| 文本 | 单条最多 2,000 个字符；Enter 或发送按钮追加客户消息，空白不发送，超限时提示并阻止追加 |
| 附件 | 选择后直接追加；单个文件名最多 255 个字符；图片展示，音视频播放，普通文件展示类型、名称和大小；超限或读取失败时提示且不追加该文件 |
| 消息时间 | 默认隐藏；点击显示，再点隐藏，同时只显示一条消息时间 |
| 窗口 | 初始展开，支持收起、重新打开；图标、位置、边距及设备可见性跟随草稿 |

切换配置组保留消息；切换语言、渠道或重新进入详情后重置初始内容。不提供清空会话按钮。预览可展示的文件不代表客户侧允许上传同类文件。

#### 安装代码

创建成功或点击顶部「安装代码」打开弹窗，展示当前渠道代码，提示放在网页 `</body>` 前，提供「复制代码」。复制成功再反馈成功，失败提示重试，代码继续可见。

修改名称、品牌或 Agent 不生成新代码。有效安装回执更新列表连接状态；不提供手动安装检测或安装记录列表。

### 2.2.4 客户聊天窗口

**功能定义：**客户在网站内通过悬浮入口咨询，查看当前身份在该网站范围内的历史。

| 模块 | 功能与交互 |
|---|---|
| 悬浮入口 | 默认收起，点击打开；按设备展示配置决定是否显示 |
| 头部 | LOGO、品牌名称、非空签名、提示音开关和收起按钮；品牌名称为空使用渠道名称 |
| 消息区 | 连续显示当前客户可访问的消息，按客户时区日期分隔；初始最近 40 条，向上每批加载最多 40 条并保持位置，失败可重试且保留已显示内容 |
| 文本 | 单条最多 2,000 个字符，换行计入字符数；Enter 发送、Shift + Enter 换行；输入法组合输入不误发；无有效文本或附件时不能发送；超限时提示并阻止发送，不截断内容 |
| 表情 | 插入光标处或替换选区，关闭面板并恢复焦点 |
| 发送状态 | 发送中防重复；离线或失败保留可恢复内容并允许重试，同一消息不重复记录，也不重复创建会话 |
| 不可用状态 | 渠道停用或实际接待 Agent 不可用时禁止发送；域名失去授权时同时禁止历史读取；渠道删除后入口不再服务 |

**附件：**

| 规则 | 要求 |
|---|---|
| 选择方式 | 点击多选、粘贴或拖入输入区 |
| 数量与大小 | 待发最多 5 个，单文件最大 20 MB；按剩余额度顺序接收合法文件，拒绝超额或非法项，保留其他合法文件 |
| 上传状态 | 逐文件展示上传状态，失败可重试或移除；选择或上传文件不创建会话 |
| 待发附件 | 文件名最多 255 个字符；展示名称、类型、大小、缩略图或图标，可逐项移除；上传成功后暂存 24 小时，到期清理并提示重新上传；文件名超限时拒绝该文件并保留其他合法文件 |
| 发送 | 可与文本一起发送，归属同一会话；过期附件排除，有效内容可继续发送 |
| 查看 | 图片可放大，音视频支持时播放，不能预览的合法格式可下载；读取失败可重试 |
| 安全 | 校验实际文件类型，不能仅改后缀绕过；查看和下载须校验会话权限，不得仅凭分享的附件链接读取他人文件 |

| 类型 | 允许格式 |
|---|---|
| 图片 | JPG、JPEG、PNG、WEBP、GIF、HEIC |
| 文档 | PDF、DOC、DOCX、TXT |
| 表格 | XLS、XLSX、CSV |
| 演示文档 | PPT、PPTX |
| 音频 | MP3、WAV、M4A、OGG |
| 视频 | MP4、MOV、WEBM |

不支持压缩包、SVG、脚本或可执行文件。正式消息及附件自发送成功起保留六个自然月，到期不可查看或下载，并清理过期内容。

**通知：**仅新 AI 消息触发未读和提示音，历史加载、初始化和客户发送不触发。未读按消息条数累计，按实际阅读清除；入口收起时显示角标，超过 99 显示 `99+`。查看历史时不强制滚动，提供新消息提示并可回到最新。同一次连续 AI 回复即使拆成多条也只响一次。提示音默认开启，客户可切换并按浏览器和渠道保存；浏览器拦截声音不影响聊天和文字提示。

## 2.3 聊天页面

**功能定义：**创建独立聊天链接，供客户直接访问或从业务平台进入咨询。

### 2.3.1 渠道列表

| 字段／操作 | 功能说明 |
|---|---|
| 搜索、新建 | 搜索词最多 50 个字符；按名称搜索；「添加新连接」打开创建弹窗 |
| 列表字段 | 渠道名称、接待 AI Agent、创建时间、启用状态、更多操作；不展示安装连接状态 |
| 编辑、启停、删除 | 与 2.2.1 相同；点击名称或编辑进入详情 |
| 排序、分页、空态、失败 | 与 2.2.1 相同 |

### 2.3.2 新增渠道

弹窗标题为「接入 聊天页面」。

| 字段／操作 | 必填／默认值 | 功能说明 |
|---|---|---|
| 渠道名称 | 是／空 | 1～50 个字符；创建和编辑均按全部渠道类型检查重名，忽略大小写与首尾空格 |
| 界面语言 | 是／自动 | 选项同网站小部件；自动按浏览器语言、英语依次匹配 |
| 接待 AI Agent | 是／未选择 | 仅可选已发布 Agent；正在接待则渠道默认启用，否则默认停用 |
| 创建 | 主操作 | 校验通过生成固定 URL，展示「与客户分享您的聊天页面」弹窗；失败保留输入，禁止重复提交 |
| 取消／关闭 | — | 有未保存内容先确认，无修改直接退出 |

不展示网站域名。分享弹窗提供只读链接、「复制链接」「打开聊天页面」；关闭后回到列表，不撤销创建。

### 2.3.3 渠道详情

| 模块 | 功能与交互 |
|---|---|
| 顶部操作栏 | 返回、渠道名称、启停；不展示安装代码；保存、取消、离开保护与冲突处理同 2.2.3 |
| 基本设置 | 渠道名称、界面语言、接待 AI Agent；不展示网站域名，名称校验及 Agent 规则同创建 |
| 品牌外观 | 品牌名称、签名、LOGO、主题色；默认值、上传及可读性规则同 2.2.3，各渠道独立保存 |
| 聊天链接 | 只读「聊天页面 URL」、复制图标和「打开聊天页面」；新标签页打开，复制失败可重试；不需要先保存 |
| 预览 | 铺满右侧区域，无悬浮按钮或收起操作；消息、媒体、时间及草稿联动规则同网站小部件预览 |

不提供可见性与位置、二维码、聊天设置或自定义域名。改名、改品牌和改绑不改变 URL；停用后原 URL 可打开但不可发送，恢复启用后继续使用；删除后永久失效。

### 2.3.4 客户聊天界面

| 模块 | 功能与交互 |
|---|---|
| 页面 | PC 与移动端全页聊天，无悬浮按钮、收起入口或额外开始页；键盘弹出后输入区保持可操作 |
| 头部与消息 | 品牌头部、文本、表情、附件、历史、失败恢复及权限规则同 2.2.4 |
| 访问方式 | 普通公开链接按匿名身份进入；业务平台传入可信登录身份时，先验证再加载对应历史，不要求客户再次手工输入账号密码 |
| 链接分享 | 接收者使用自己的合法身份，不共享发送者的消息；URL 不能包含可直接冒用的用户 ID 或长期有效身份凭证 |
| 标签标题 | 正常显示品牌名称，空时回退渠道名称；后台收到新 AI 消息显示「(N) 品牌名称」，实际阅读后清除，恢复标题 |

客户身份及历史关联按 2.4 执行；聊天页面按渠道隔离，每个渠道对应一个业务平台场景，不混用互不相关平台的账号体系。

## 2.4 会话规则

### 2.4.1 客户身份与历史关联

| 场景 | 处理规则 |
|---|---|
| 匿名访问 | 只读取当前渠道和身份范围内自己的历史；匿名名称为 `Visitor #` 加六位数字；身份有效时可回访恢复，清除浏览器数据、隐身或换设备不保证恢复 |
| 已登录访问 | 验证可信身份、凭证有效期和渠道／网站范围后加载历史；同一范围的同一账号可跨设备查看保留期内历史 |
| 网站身份范围 | 同一渠道中，主域名与 `www` 共用范围；其他子域、其他主域分别隔离。获准展示不代表可读取其他范围历史 |
| 聊天页面身份范围 | 按渠道隔离，不同渠道不合并历史，即使 Agent 相同 |
| 匿名转登录 | 验证成功后自动关联当前匿名身份、当前渠道及网站范围内全部尚未归属其他账号的会话，无额外确认；已属其他账号的记录不得转移 |
| 退出或切换账号 | 立即隐藏上一账号历史、敏感草稿和未读，使原身份授权失效；新账号验证后才能读取其历史 |
| 验证失败或过期 | 不显示所声称账号的历史，不执行关联；允许重试或合法匿名访问 |

网站来源、身份与凭证须可靠验证，不能仅信任客户端自报域名、用户 ID 或公开聊天链接；不新增运营人员手工输入客户身份的配置页。

**关联后存在多个进行中会话：**

- 登录前的匿名会话 B 与账号原有会话 A 独立，不合并，不改写 Agent、创建时间或归属。
- 当前页面继续 B，仅 B 可以触发新的主动跟进；A 按原超时安排关闭。
- B 关闭后不自动切回 A；客户再次成功发送时创建新会话 C，由渠道当前 Agent 接待。
- 各会话有权访问的历史仍按消息时间连续展示，仅显示六个自然月内的内容。

### 2.4.2 客户进入与离开

| 场景 | 处理规则 |
|---|---|
| 打开入口、查看欢迎内容或选择附件 | 不创建正式会话 |
| 首次成功发送 | 无当前可继续会话时创建新会话，记录客户、渠道与实际接待 Agent；有当前会话则继续写入 |
| 收起、退出页面或停用渠道 | 不直接改变会话结果；离开页面后超时计时仍继续 |
| 会话关闭后再次发送 | 创建新会话，使用渠道当前 Agent；不提前恢复其他非当前会话 |
| 改绑 Agent | 旧会话保留原 Agent；原 Agent 不可用时禁止发送，不因改绑提前转接 |
| 停用渠道或实际 Agent | 停止客户发送和后续 AI 输出，已发送内容保留；恢复后不补发取消的回复，未超时且原 Agent 可用时继续原会话 |
| 改名、删除渠道 | 不追溯改写历史渠道和 Agent 归属；删除后不可继续接待，历史按保留期保存 |

### 2.4.3 接待话术

- 欢迎语、跟进语、结束语使用实际接待 Agent 的配置，渠道不另设一套。
- 打开入口可展示欢迎内容；首次发送创建会话后不重复推送已展示的欢迎内容。刷新或收起再打开也不重复触发。
- 跟进仅作用于当前正在接待的会话，超时关闭时按既有话术配置发送结束语。
- 渠道或实际 Agent 停用后不再发送自动话术，恢复后不补发。
