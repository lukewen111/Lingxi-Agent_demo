# Adam Bot新增【总览】功能需求文档

## 一、需求背景

当前 AI Agent 工作台缺少集中查看接待表现的入口，用户难以快速了解会话规模、AI 独立解决情况及转人工情况。本次新增「总览」功能，通过核心指标、较上期对比和趋势图，支持按时间、AI Agent 和渠道查看接待表现。

## 三、功能详细说明

### 1．新增【总览】功能

#### 功能说明

在 AI Agent 工作台新增「总览」一级菜单，以单页看板展示会话数、AI 解决率、转人工率及较上期变化，支持按时间、AI Agent 和渠道筛选，并切换查看对应趋势。登录后默认进入收件箱的规则保持不变。

页面布局与控件样式参考配套产品原型。页面包含筛选区、三张指标卡片和一张趋势图，右上角提供「刷新」操作。

#### 1.1 筛选

| 字段 | 默认值 | 功能说明 |
|---|---|---|
| 时间范围 | 近 7 天 | 单选「今天」「近 7 天」「近 30 天」「自定义日期范围」；选择自定义后展示日期范围选择器 |
| AI Agent | 全部 AI Agent | 单选，选项包含「全部 AI Agent」和当前仍存在的 Agent 名称，未发布或未开启接待的 Agent 也可选择 |
| 渠道 | 全部渠道 | 单选，选项包含「全部渠道」和当前仍存在的具体渠道实例；实例以「渠道类型图标＋渠道名称」展示 |

**时间范围**

| 选项 | 统计范围 |
|---|---|
| 今天 | 当天 00:00 至当前时刻 |
| 近 7 天 | 今天及之前 6 个自然日，截至当前时刻 |
| 近 30 天 | 今天及之前 29 个自然日，截至当前时刻 |
| 自定义日期范围 | 包含所选开始日期和结束日期；包含今天时截至当前时刻，历史日期按完整自然日统计 |

日期边界和趋势分组统一采用当前用户浏览器时区。自定义结束日期不得早于开始日期。

**组合筛选**

- 时间、AI Agent、渠道取交集，任一条件变更后自动更新指标、较上期数据及趋势图。
- Agent 与渠道的选项相互独立，不根据当前绑定关系缩减候选项。
- Agent 和渠道均按会话创建时的归属筛选。渠道改绑后，仍可选择「旧 Agent＋原渠道」查询历史会话。
- 已删除的 Agent 或渠道不再出现在筛选选项中，其历史会话仍计入「全部」汇总；停用不影响历史统计。
- 筛选结果为空时保留已选条件。

#### 1.2 核心指标

三张卡片统一采用「指标名称 → 当前值＋涨跌标签 → 对比上期＋上期数值」的结构。卡片仅展示数据，不支持点击下钻或跳转收件箱。指标名称旁提供口径说明，鼠标悬停或键盘聚焦时展示。

按当前筛选条件得到正式会话集合，定义以下统计量：

| 统计量 | 定义 |
|---|---|
| N：会话数 | 不同 Conversation 的数量，包含处理中和已结束会话 |
| E：已结束会话数 | 已按既有生命周期规则关闭的会话数量，包含已解决会话 |
| R：AI 已解决会话数 | 已结束、经既有 LLM 规则判定由 AI 独立解决，且未执行转人工指令的会话数量 |
| T：转人工会话数 | 实际执行过转人工指令的不同会话数量，每场最多计 1 次 |

| 指标 | 计算公式 | 展示规则 |
|---|---|---|
| 会话数 | N | 整数、千分位，例如 `1,286`；不添加「场」等量词 |
| AI 解决率 | R ÷ E × 100% | 保留 1 位小数，例如 `72.5%`；E＝0 时显示 `—` |
| 转人工率 | T ÷ N × 100% | 保留 1 位小数，例如 `18.2%`；N＝0 时显示 `—` |

分母大于 0、分子为 0 时显示 `0.0%`。计算使用原始分子和分母，仅在展示时四舍五入。AI 解决率和转人工率的分母不同，两者之和不要求等于 100%。

**统计口径**

- 仅统计当前租户正式业务渠道产生的会话；AI Agent「预览与测试」中的聊天不计入。
- 按唯一 Conversation 去重，同一会话内的多条消息、欢迎语、跟进语和多次回复不增加会话数。
- 正式渠道中仅包含问候或测试内容的会话仍计入 N；单纯问候、测试、无关内容或未实际解决问题的会话不计入 R。
- AI 已解决须满足会话已结束、AI 至少解决一个实际客户问题、无需人工介入，并经既有 LLM 规则判定。执行过转人工指令的会话不得计入 R，即使 AI 此前解决过部分问题。
- 仅聊天文本提及人工不计入 T；实际执行转人工指令即计入，不以人工客服接待成功为条件。
- 执行转人工指令不代表会话立即结束。尚未结束时计入 N、T，不计入 E、R；后续结束时增加 E，N、T 不重复增加，R 仍为 0。
- 所有统计均按会话创建时间归属。后续结束或判定变化时，重新加载可更新历史日期的结果。
- 会话关闭后客户再次发消息，按既有规则创建新的 Conversation，新会话可计为 1 场。本次不调整会话生命周期或收件箱分类。

#### 1.3 较上期对比

本期和上期使用相同的 Agent、渠道筛选条件，仅平移时间范围。三个指标的当前值、上期值及变化值同步更新；趋势图不增加上期曲线。

**上期范围**

| 当前时间筛选 | 上一期范围 |
|---|---|
| 今天 | 昨天 00:00 至昨天与当前相同的时分 |
| 近 7 天 | 当前 7 个自然日前一组连续 7 个自然日 |
| 近 30 天 | 当前 30 个自然日前一组连续 30 个自然日 |
| 自定义日期范围 | 紧邻开始日期之前、自然日数量相同的一段日期 |

当本期包含今天时，上期最后一天同样截至当前本地时分；本期结束日期早于今天时，两期均统计完整自然日。上期同样按会话创建时间筛选，并使用最新会话结果。

例如，11 月 12 日 13:35 查看近 7 天：本期为 11 月 6 日 00:00 至 11 月 12 日 13:35，上期为 10 月 30 日 00:00 至 11 月 5 日 13:35。

**计算与展示**

| 指标 | 变化公式 | 示例 |
|---|---|---|
| 会话数 | （本期 N－上期 N）÷ 上期 N × 100% | 本期 200、上期 100：`↑ 100.0%`；底部为 `对比上期 100` |
| AI 解决率 | 本期 R/E × 100－上期 R/E × 100 | 本期 70.0%、上期 60.0%：`↑ 10.0 p.p.`；底部为 `对比上期 60.0%` |
| 转人工率 | 本期 T/N × 100－上期 T/N × 100 | 本期 18.2%、上期 22.0%：`↓ 3.8 p.p.`；底部为 `对比上期 22.0%` |

- 会话数变化使用相对增幅 `%`，两项比率变化使用百分点 `p.p.`，均保留 1 位小数。
- 使用原始值计算差异，最终展示时四舍五入。
- 正数显示 `↑`，负数显示 `↓`，相等时显示 `0.0%` 或 `0.0 p.p.`，不显示箭头。
- 变化标签紧邻当前值；底部统一为「对比上期＋上期数值」，不重复指标名称。
- 会话数涨跌采用中性表达；AI 解决率上升、转人工率下降采用积极变化样式，反向采用消极变化样式。颜色仅辅助表达，保留箭头和数值。

**边界处理**

| 场景 | 变化标签 |
|---|---|
| 上期 N＞0 | 会话数按相对增幅正常计算 |
| 上期 N＝0、本期 N＞0 | 会话数显示「新增」 |
| 本期和上期 N 均为 0 | 会话数显示 `—` |
| 任一期 E＝0 | AI 解决率对比显示 `—`，主值仍按本期计算 |
| 任一期 N＝0 | 转人工率对比显示 `—`，主值仍按本期计算 |
| 任一期数据获取失败 | 按加载失败处理，不显示为 0 或涨跌 |

#### 1.4 数据趋势

仅展示一张折线图，支持切换「会话数」「AI 解决率」「转人工率」，默认选中「会话数」。每次只展示一个指标，复用顶部筛选条件。

| 时间范围 | 统计粒度 |
|---|---|
| 今天 | 按小时 |
| 近 7 天、近 30 天 | 按天 |
| 自定义日期范围 ≤30 天 | 按天 |
| 自定义日期范围 31～90 天 | 按周 |
| 自定义日期范围 ＞90 天 | 按月 |

- 周一为周起始；范围边界处的周或月只统计所选日期内的数据。
- 每个时段按会话创建时间归属，两项比率使用该时段原始分子和分母重新计算，不平均每日或每小时百分比。
- 悬停只展示时间和当前指标值：会话数为整数，比率保留 1 位小数。
- 某时段会话数为 0 时绘制数值 0；比率分母为 0 时不绘制该点，且不跨越该点连接曲线，悬停显示「暂无可计算数据」。
- 当前筛选范围没有会话时，整个图表区域显示「暂无数据」；有会话但当前指标所有时段均无法计算时，显示「暂无可计算数据」。

#### 1.5 刷新与页面状态

首次进入、切换筛选条件或点击「刷新」时获取最新数据。手动刷新保留筛选条件，页面不自动定时刷新或实时推送。

| 状态 | 页面处理 |
|---|---|
| 首次加载中 | 保留指标卡片和趋势图布局，展示加载占位 |
| 加载成功 | 同步展示当前值、上期值、变化标签和趋势 |
| 筛选结果为空 | 保留完整看板和筛选条件；会话数 `0`，两项比率 `—`，趋势区「暂无数据」；上期值和变化标签仍按对比规则计算 |
| 有会话但无已结束会话 | 会话数显示实际值，AI 解决率 `—`，转人工率按 T/N 计算 |
| 手动刷新中 | 保留原有数据，刷新按钮显示加载状态，完成后同步更新 |
| 加载或刷新失败 | 显示失败提示和重试入口，保留可用的上次成功数据；无历史结果时显示失败状态，不以 0 代替 |
| 点击重试 | 按当前筛选条件重新获取数据 |

### 2．角色权限新增【总览】选项

#### 功能说明

在现有「设置 → 成员与权限 → 角色管理」的 AI Agent 工作台菜单权限中，新增一级选项「总览」。

- Owner 默认拥有总览权限。
- 其他角色默认不勾选，可通过现有角色编辑功能授权。
- 勾选后的访问控制及权限生效机制沿用现有角色权限规则。

## 四、功能验收

| 编号 | 所属功能 | 验收场景 | 预期结果 |
|---|---|---|---|
| AT-01 | 新增【总览】功能 | 首次进入 | 默认近 7 天、全部 AI Agent、全部渠道和会话数趋势；登录默认仍为收件箱 |
| AT-02 | 新增【总览】功能 | 组合筛选 | 时间、Agent、渠道取交集；两个下拉独立；空结果不重置筛选 |
| AT-03 | 新增【总览】功能 | 正式会话与预览聊天 | 正式会话按 Conversation 去重；预览聊天不计入；正式问候会话计入 N 但不自动计入 R |
| AT-04 | 新增【总览】功能 | 已结束且 AI 独立解决 | 计入 N、E、R；已结束未解决的会话仅计入 N、E |
| AT-05 | 新增【总览】功能 | 转人工后尚未结束，再超时关闭 | 起初计入 N、T；关闭后增加 E，不增加 R，不重复计算 N、T |
| AT-06 | 新增【总览】功能 | 空分母与零分子 | N＝0 时主值为 0／—／—；E＝0 时解决率为 —；分母有效且分子为 0 时比率为 0.0% |
| AT-07 | 新增【总览】功能 | 历史归属与对象变化 | 跨日结束仍归属创建日；改绑不改变历史 Agent；删除对象退出选项但历史保留，停用不移除历史 |
| AT-08 | 新增【总览】功能 | 上期范围 | 连续等量自然日；本期包含今天时上期末日按相同时分截断，历史日期段按完整自然日比较 |
| AT-09 | 新增【总览】功能 | 对比公式 | 会话数 100→200 显示 ↑100.0%；解决率 60%→70% 显示 ↑10.0 p.p.；转人工率 22%→18.2% 显示 ↓3.8 p.p. |
| AT-10 | 新增【总览】功能 | 对比边界 | 上期 N＝0、本期有数据显示「新增」；双方 N＝0 显示 —；比率任一期分母为 0，对比为 —；相等时无箭头 |
| AT-11 | 新增【总览】功能 | 趋势粒度 | 今天按小时；30／31／90／91 天自定义范围分别按天／周／周／月；周一为周起始，边界只统计所选日期 |
| AT-12 | 新增【总览】功能 | 趋势计算与悬停 | 比率按时段原始量重算；仅显示一个指标；悬停仅有时间及该指标值；无效比率断线 |
| AT-13 | 新增【总览】功能 | 更新与失败 | 筛选或刷新同步更新所有结果；刷新保留条件和旧数据；失败可重试且不冒充空数据；无定时刷新 |
| AT-14 | 新增【总览】功能 | 只读边界与统计范围 | 卡片不下钻、不联动收件箱；仅统计当前租户；时间边界按浏览器时区；不改变既有会话生命周期 |
| AT-15 | 角色权限新增【总览】选项 | 查看角色权限 | 菜单权限中新增一级选项「总览」 |
| AT-16 | 角色权限新增【总览】选项 | 检查默认权限 | Owner 默认拥有总览权限，其他角色默认不勾选 |
| AT-17 | 角色权限新增【总览】选项 | 勾选或取消「总览」 | 按现有权限机制生效；授权后可访问，取消后不显示菜单且直接访问受限 |
