# IM项目新增【网站小部件／聊天页面】渠道功能需求文档

# 1．产品原型

以当前项目高保真产品原型为准：进入【渠道】，查看【网站小部件】和【聊天页面】。

本文参考《IM项目新增【AI客服】功能需求文档》的写法，按页面说明功能、字段和交互；两种渠道共用的规则只写一次。Livechat、Telegram 沿用现有功能，本次不调整。

# 2．功能需求描述

## 2.1 渠道入口与列表

**功能定义：**创建和管理网站小部件、聊天页面，为客户提供连接 AI 客服的咨询入口。

- 网站小部件：将代码安装到网站，客户通过悬浮按钮打开聊天窗口。
- 聊天页面：生成独立聊天链接，客户打开链接后进入完整聊天页面。
- 一个渠道绑定一个接待 AI Agent；同一个 AI Agent 可以被多个渠道绑定。

### 2.1.1 全部渠道

| 模块 | 字段 | 定义与交互 |
|---|---|---|
| 类型卡片 | 图标、名称、说明 | 展示渠道类型及使用场景 |
| 类型卡片 | 已连接数量 | 有实例时展示「已连接 N」；包含启用和停用实例，不代表安装成功数量 |
| 类型卡片 | 添加／管理 | 无实例时，网站小部件显示「添加网站」，聊天页面显示「添加新连接」；有实例时显示「管理」，进入对应列表 |

### 2.1.2 渠道列表

| 模块 | 字段 | 定义与交互 |
|---|---|---|
| 搜索栏 | 搜索 | 按渠道名称模糊搜索，忽略首尾空格和大小写；清空恢复全部 |
| 新建入口 | 添加网站／添加新连接 | 打开当前类型的接入弹窗 |
| 列表 | 渠道名称 | 展示类型图标和名称；点击进入详情，默认打开基本设置 |
| 列表 | 接待 AI Agent | 展示头像和名称；关联对象不存在时显示「未配置」 |
| 列表 | 创建时间 | 精确到分钟；修改配置不改变创建时间 |
| 列表 | 状态 | 仅网站小部件展示「未连接／已连接」，与启用状态独立 |
| 列表 | 启用状态 | 开关；操作后立即生效，无须额外保存 |
| 列表 | 更多操作 | 编辑：进入详情；删除：仅停用渠道可操作 |
| 列表 | 排序与分页 | 创建时间倒序，每页 20 条 |
| 空状态 | 无渠道／无搜索结果 | 无渠道时提供创建入口；搜索无结果时保留搜索框，支持修改或清空 |

## 2.2 新增渠道

**功能定义：**填写基础信息、绑定接待 AI Agent，生成渠道专属代码或链接。

### 2.2.1 接入弹窗

类型由创建入口确定，不可切换；创建后也不可修改类型。字段顺序如下，聊天页面不展示网站域名。

| 字段 | 必填／默认值 | 功能说明 |
|---|---|---|
| 渠道名称 | 是／空 | 创建时去首尾空格，不可为空；与全部渠道名称比较，不区分大小写，不可重名 |
| 网站域名 | 网站小部件必填／空 | 填写主要网站域名；支持将 `https://www.example.com/` 转为 `www.example.com` |
| 界面语言 | 是／自动 | 自动、简体中文、繁体中文、英语、越南语、泰语、高棉语、缅甸语、老挝语；仅控制界面文案，不改变 AI 回复语言配置 |
| 接待 AI Agent | 是／未选择 | 单选，展示头像与名称；创建与编辑的候选范围差异见第 4 章 |
| 添加网站／创建 | 主操作 | 校验通过后创建；提交中显示加载状态，避免重复提交 |
| 取消／关闭 | — | 放弃本次输入；当前两个入口的确认行为不同，见第 4 章 |

**网站域名校验：**

- 接受普通域名或 HTTPS 根地址，保存为小写域名；去除首尾空格及末尾域名点。
- 不接受 HTTP、IP、通配符、端口、账号信息、查询参数、片段或根路径以外的路径。
- 空值提示「请输入网站域名」；格式不合法时提示修正，不创建渠道。

### 2.2.2 创建结果

| 类型 | 创建后结果 |
|---|---|
| 网站小部件 | 默认启用、未连接；生成安装代码，展示「安装网站小部件」弹窗 |
| 聊天页面 | 默认启用；生成固定 URL，展示「与客户分享您的聊天页面」弹窗 |

关闭结果弹窗后回到渠道列表，不自动进入详情，也不撤销已创建渠道。创建失败或校验不通过时保留输入，不生成重复记录。

## 2.3 渠道详情页

**功能定义：**配置渠道基础资料、品牌和接入方式，并在同页预览展示效果。

网站小部件包含【基本设置】【品牌外观】【可见性与位置】；聊天页面包含【基本设置】【品牌外观】【聊天链接】。右侧持续展示预览。

### 2.3.1 顶部与保存

| 字段／操作 | 功能与交互 |
|---|---|
| 返回 | 返回当前类型列表；有未保存修改时，确认放弃或继续编辑 |
| 渠道名称 | 展示当前配置的名称 |
| 安装代码 | 仅网站小部件展示，打开安装代码弹窗 |
| 已启用／已停用 | 切换后立即生效，与配置保存独立；停用需要二次确认 |
| 保存 | 仅保存当前分组；成功后清除该组未保存标记，不覆盖其他组草稿 |
| 取消 | 仅恢复当前分组最近保存值，其他组修改保留 |
| 未保存标记 | 修改后对应导航项显示圆点；切换分组保留草稿，预览同步显示草稿效果 |

未编辑时保存、取消不可用。刷新或关闭浏览器时，有未保存修改则提示离开；客户使用已保存配置，不使用管理员尚未保存的草稿。

### 2.3.2 基本设置

| 字段 | 功能说明 |
|---|---|
| 渠道名称 | 必填，支持修改；不改变渠道标识、代码或链接 |
| 网站域名 | 仅网站小部件展示，必填；校验同创建；修改不自动调整允许域名 |
| 界面语言 | 选项同创建；默认读取已保存值 |
| 接待 AI Agent | 单选；详情只展示已发布且正在接待的 Agent；更换仅对新会话生效，既有会话保留原 Agent |

### 2.3.3 品牌外观

| 字段 | 必填／默认值 | 功能说明 |
|---|---|---|
| 品牌名称 | 否／空 | 空时以渠道名称作为占位和客户展示名称；手动填写后与渠道名称独立维护 |
| 签名 | 否／有问题？我们随时为您提供帮助。 | 展示在品牌名称下方；清空后隐藏，不表示实时在线状态 |
| 品牌 LOGO | 否／文字占位 | 点击图片区域上传或更换，已有图片可删除；支持图片，最大 2 MB |
| 主题色 | 默认 `#1c1f26` | 支持颜色选择器和 HEX 输入；保存时必须为 `#` 加六位十六进制字符 |

上传图片或修改外观后立即更新预览，保存后对客户生效。非法图片、超限文件或读取失败时提示原因，并保留原配置。

### 2.3.4 可见性与位置

**功能定义：**仅网站小部件使用，配置允许展示的网站及不同设备的悬浮入口。

| 字段 | 默认值 | 功能与交互 |
|---|---|---|
| 允许域名 | 空 | 留空表示不限制域名；输入后按 Enter 添加为标签，支持逐项移除；不自动带入网站域名 |
| 悬浮按钮图标 | 默认消息图标 | 三种预设图标或自定义图片，单选；自定义图片最大 2 MB，按比例裁切并铺满圆形入口 |
| 恢复默认图标 | 自定义时展示 | 清除自定义图标，恢复默认消息图标 |
| 设备 | 桌面端 | 桌面端／移动端；切换后编辑对应设备，并同步切换预览 |
| 展示 | 两端均开启 | 分设备控制是否显示入口，不改变渠道启用状态 |
| 按钮位置 | 两端均为右侧 | 左侧底部／右侧底部，分别保存 |
| 侧边距 | 两端均为 24px | 0～100 的整数，表示距所选侧边距离 |
| 底部间距 | 两端均为 24px | 0～100 的整数，表示距底部距离 |

- 允许域名校验同网站域名；重复添加时提示「该域名已添加」，不重复保存。
- 当前按所填域名及其子域匹配，例如 `example.com` 包含 `shop.example.com`；来源不匹配时，不展示客户历史并禁止发送。可信来源和身份隔离规则见第 4 章。
- 桌面端与移动端配置互不覆盖；当前页面宽度小于 768px 使用移动端配置。
- 两端均隐藏时允许保存，并提示「所有设备均已隐藏，客户将看不到网站小部件。」；隐藏入口不删除历史会话。

### 2.3.5 安装代码与聊天链接

| 模块 | 字段／操作 | 功能说明 |
|---|---|---|
| 网站小部件 | 安装代码弹窗 | 创建成功或点击详情顶部入口打开；展示代码，并提示放在网页 `</body>` 前 |
| 网站小部件 | 复制代码 | 复制当前渠道专属代码；关闭弹窗不改变配置 |
| 网站小部件 | 连接状态 | 初始未连接，识别到客户入口加载后显示已连接；真实安装判据见第 4 章 |
| 聊天页面 | 聊天页面 URL | 只读；创建结果弹窗及详情【聊天链接】均可查看 |
| 聊天页面 | 复制链接／打开聊天页面 | 复制当前 URL，或在新标签页打开客户聊天页面 |

修改名称、品牌或 Agent 不改变代码和链接。不提供二维码、手动安装检测、安装记录列表或自定义聊天域名。

### 2.3.6 预览

**功能定义：**查看当前外观与展示配置，支持输入客户消息查看效果，不生成正式会话、不进入收件箱，也不自动生成 AI 回复。

| 模块 | 功能与交互 |
|---|---|
| 品牌头部 | 跟随当前品牌、签名、LOGO 和主题色；通知图标可切换预览静音状态 |
| 初始消息 | 一条客服消息和一条客户消息，按所选语言展示预置内容 |
| 文本输入 | Enter 或发送按钮追加客户消息；空白不发送 |
| 附件 | 选择后直接追加消息；图片直接展示，音视频可播放，其他文件展示名称、类型和大小 |
| 消息时间 | 默认隐藏；点击显示，再次点击隐藏；同时只展示一条消息时间 |
| 网站小部件 | 初始展开，支持收起和重新打开；位置、图标、设备可见性跟随配置 |
| 聊天页面 | 铺满右侧预览区域，不提供悬浮按钮和收起入口 |

切换配置分组保留消息；切换语言、渠道或重新进入详情后恢复初始内容。不提供清空会话按钮。预览附件可展示的格式，不代表客户侧允许上传相同格式。

## 2.4 渠道启停与删除

| 操作 | 规则 |
|---|---|
| 启用 | 已绑定的 Agent 必须存在、已发布且正在接待；不满足时提示「请先配置已发布且正在接待的 AI Agent」 |
| 停用 | 二次确认后立即停止接收新客户消息，历史保留；取消确认不改变状态 |
| 删除 | 仅停用渠道可删除；输入与原渠道名称完全一致后才可确认 |
| 删除结果 | 列表移除并更新类型数量；原链接或入口不再提供服务，历史会话保留 |

渠道启用、网站已连接、Agent 可接待是不同状态。客户发送还需满足渠道、实际接待 Agent 和域名规则均可用。

## 2.5 客户聊天界面

**功能定义：**客户通过网站窗口或独立聊天页面发送咨询，并继续查看当前渠道内自己的历史消息。

### 2.5.1 界面与消息

| 模块 | 功能与交互 |
|---|---|
| 头部 | 展示 LOGO、品牌名称、非空签名和提示音开关；无品牌名称时使用渠道名称 |
| 网站入口 | 默认收起；点击悬浮按钮打开，收起不结束会话；按设备配置显示 |
| 聊天页面 | 独立全页展示，不提供悬浮入口 |
| 消息区 | 连续展示当前客户在该渠道的消息，按日期分隔；初始显示最近 40 条，向上滚动每批加载最多 40 条并保持阅读位置 |
| 文本输入 | Enter 发送，Shift + Enter 换行；输入法组合输入期间不误发；无有效文本或附件时不能发送 |
| 表情 | 选择后插入当前光标或替换选区，关闭面板并恢复输入焦点 |
| 发送状态 | 发送中禁止重复提交；离线或失败时提示并提供恢复／重试，不丢失可恢复内容 |
| 不可用状态 | 渠道停用或实际接待 Agent 不可用时禁止发送，提示「当前客服暂不可用」；渠道删除后显示不存在 |

### 2.5.2 附件

| 规则 | 要求 |
|---|---|
| 上传方式 | 点击选择、粘贴或拖入输入区域；支持多选 |
| 文件数量 | 待发送区最多 5 个，包含之前已选文件；按剩余额度接收合法文件 |
| 单文件大小 | 最大 20 MB；超限拒绝该文件，保留其他合法文件 |
| 待发送区 | 展示文件名、图片缩略图或文件图标，可逐项移除；选择文件不等于发送消息 |
| 发送 | 可与文本一起提交，归属同一会话；图片展示，音视频播放，普通文件提供下载链接 |
| 临时附件 | 添加成功后 24 小时内有效；发送时排除过期文件并提示重传，有效内容可继续发送 |
| 非法文件 | 提示「不支持该文件格式」，不清空其他合法文件 |

| 类型 | 允许格式 |
|---|---|
| 图片 | JPG、JPEG、PNG、WEBP、GIF、HEIC |
| 文档 | PDF、DOC、DOCX、TXT |
| 表格 | XLS、XLSX、CSV |
| 演示文档 | PPT、PPTX |
| 音频 | MP3、WAV、M4A、OGG |
| 视频 | MP4、MOV、WEBM |

不支持压缩包、SVG、脚本和可执行文件。播放与展示受浏览器支持限制；文件安全验证、访问权限和失败回退见第 4 章。

### 2.5.3 未读消息与通知

- 仅新到达的 AI 消息触发通知；初始化、历史加载、客户自身发送不触发。
- 网站窗口收起时显示未读角标，超过 99 显示 `99+`；查看历史时收到消息不强制跳到底部，可点击新消息提示回到最新。
- 聊天页面在后台收到新 AI 消息时，标签标题显示未读数量；读完恢复品牌名称。
- 客户可独立开关提示音，默认开启，按浏览器和渠道保存；静音不影响文字未读提示。
- 浏览器不允许播放声音时，不阻断聊天；批量消息计数和已读边界见第 4 章。

## 2.6 会话与收件箱

**功能定义：**将客户消息关联到独立会话，在收件箱保留渠道、客户和实际接待 Agent 的归属。

| 场景 | 处理规则 |
|---|---|
| 仅打开入口或选择附件 | 不创建会话 |
| 首次成功发送客户消息 | 创建「处理中」会话，记录当前渠道与接待 Agent |
| 已有处理中会话 | 新消息继续进入当前会话，保持原 Agent |
| 改绑 Agent | 只对新会话生效；原会话 Agent 不可用时禁止发送，不自动转给新 Agent |
| 会话超时 | 按现有聊天超时开关和分钟数，从最近更新时间计算；到期关闭并记录系统消息 |
| 已关闭后再次发送 | 创建新会话，使用渠道当前绑定的 Agent |
| 刷新、收起或离开 | 不主动关闭会话；身份仍有效时恢复当前可访问历史 |
| 渠道改名或删除 | 不改写历史会话归属，不删除历史会话 |

匿名客户名称采用 `Visitor #` 加六位数字。不同渠道不混合展示历史；同一客户的多个会话在客户界面连续展示。当前未确认跨设备身份恢复与登录账号关联，不将其写作已具备能力。

# 3．功能验收清单

- [ ] 可分别创建两类渠道，必填、重名和域名校验有效，创建后展示对应代码或链接。
- [ ] 列表搜索、排序、分页、空态及类型数量正确。
- [ ] 两类详情配置项与原型一致，分组保存和取消不覆盖其他组修改。
- [ ] 品牌、主题、图标及两端展示设置在预览中即时更新，保存后用于客户界面。
- [ ] 网站允许域名独立配置，重复与非法输入被拦截；两端位置和边距互不覆盖。
- [ ] 代码与链接可复制、打开；改名或改绑不改变渠道入口。
- [ ] 停用需确认；启用检查 Agent；删除需停用并输入完整名称，历史保留。
- [ ] 管理预览能展示文本与附件，不自动回复、不生成收件箱会话。
- [ ] 客户文本、表情、附件可发送，格式、20 MB 和 5 个文件限制有效，失败可恢复。
- [ ] 仅打开不建会话，成功发送才新建或续接；改绑不影响原会话归属。
- [ ] 历史分批加载、日期分隔和超时关闭符合规则。
- [ ] 新 AI 消息触发未读与提示音，客户消息和历史初始化不触发；静音偏好保持。
