## 1．需求目标与范围

### 1.1 业务问题与目标

为需要在网站内接待客户、或通过独立链接提供咨询入口的企业管理员，提供可独立配置的渠道实例，使客户能够找到对应 AI Agent、发起咨询，并在收件箱中形成可追踪的会话。

两种渠道分别解决以下任务：

| 渠道 | 管理员任务 | 客户使用方式 | 完成结果 |
|---|---|---|---|
| 网站小部件 | 创建网站渠道、配置品牌和展示规则、取得安装代码 | 在网站中点击悬浮入口打开聊天窗口 | 在当前网页内咨询，消息归属相应渠道 |
| 聊天页面 | 创建链接渠道、配置品牌、取得固定聊天链接 | 打开独立 URL 进入聊天页 | 在独立页面咨询，消息归属相应渠道 |

### 1.2 本期范围

包含渠道入口和实例列表、创建、分组配置、外观预览、安装代码或聊天链接、启停与删除，以及客户侧文本、表情、附件、历史、通知、会话与收件箱关联。

一个渠道只能配置一个接待 AI Agent；一个 AI Agent 可以关联多个渠道。渠道标识在创建时生成，修改名称、品牌、展示设置和接待 Agent 不重新生成渠道标识。

本次不重写 Livechat、Telegram 的凭证接入需求，不新增渠道类型、营销首页、自定义聊天域名、渠道统计页面、转人工配置、独立客户身份管理页或渠道专属权限体系。

已从当前范围移除的页面入口：聊天设置、二维码、安装记录列表、手动检测安装、管理端清空预览会话，以及渠道列表的状态和 Agent 筛选。

### 1.3 角色与业务对象

| 对象 | 定义与边界 |
|---|---|
| 管理员 | 创建与管理渠道；本文不扩展现有工作台的角色权限模型 |
| 客户 | 使用公开聊天入口的访客；当前可确认匿名访问，可信登录身份接入另见待确认事项 |
| 渠道实例 | 具有独立名称、类型、Agent、配置、启停状态和入口的业务对象 |
| 品牌名称 | 客户侧展示名称；与后台渠道名称分开维护 |
| 连接状态 | 网站小部件是否被识别为已连接；不是启用状态，也不保证 Agent 可接待 |
| 当前会话 | 当前客户在该渠道尚未关闭、可以继续发送消息的 Conversation |
| 预览消息 | 管理员在配置页查看效果所用的消息，不进入正式收件箱 |

## 2．产品路径与页面职责

### 2.1 页面关系

```text
渠道
├─ 全部渠道：类型卡片与已连接数量
├─ 网站小部件：实例列表／接入弹窗／创建后的安装弹窗
│  └─ 详情：基本设置、品牌外观、可见性与位置、预览
│     └─ 顶部安装代码弹窗
└─ 聊天页面：实例列表／接入弹窗／创建后的链接分享弹窗
   └─ 详情：基本设置、品牌外观、聊天链接、预览

客户入口
├─ 网站悬浮按钮 → 聊天窗口
└─ 独立聊天 URL → 聊天页面
   └─ 成功发送客户消息 → Conversation → 收件箱
```

该结构仅说明页面关系，具体布局与控件形态以配套高保真页面为准。

### 2.2 核心操作闭环

| 用户任务 | 路径与结果 |
|---|---|
| 首次创建 | 类型入口 → 填写接入信息 → 校验 → 创建实例 → 弹出安装代码或聊天链接 → 关闭弹窗回到实例列表 |
| 调整外观 | 列表点击名称或编辑 → 品牌外观 → 调整字段 → 同页预览 → 保存当前分组 |
| 配置网站展示 | 网站详情 → 可见性与位置 → 允许域名、图标、分设备配置 → 保存 |
| 发起咨询 | 客户打开可用入口 → 输入文本或选择附件 → 发送成功 → 新建或继续会话 → 收件箱可查看 |
| 停用与删除 | 列表或详情停用并确认 → 列表删除 → 输入完整渠道名称 → 确认删除；历史会话保留 |

## 3．发现渠道与创建实例

### 3.1 全部渠道入口

侧边导航提供「全部」「网站小部件」「Livechat」「Telegram」「聊天页面」。全部页的类型卡片展示类型图标、名称、场景说明与操作入口。

| 元素 | 条件与展示 | 操作结果 |
|---|---|---|
| 已连接数量 | 当前类型存在实例时显示「已连接 N」；数量统计该类型全部实例，包含停用实例 | 仅表示实例数量，不表示网站安装成功数 |
| 网站小部件创建入口 | 无实例时显示「添加网站」 | 进入该类型并打开创建弹窗 |
| 聊天页面创建入口 | 无实例时显示「添加新连接」 | 进入该类型并打开创建弹窗 |
| 管理入口 | 类型已有实例时显示「管理」 | 打开该类型实例列表 |

### 3.2 创建弹窗

网站小部件标题为「接入 网站小部件」，聊天页面标题为「接入 聊天页面」。类型由入口确定，不提供切换字段；创建后不能修改类型。

字段按下表顺序排列；聊天页面跳过网站域名。

| 字段 | 控件 | 必填 | 初始值 | 定义与校验 |
|---|---|---|---|---|
| 渠道名称 | 单行输入 | 是 | 空 | 创建时去首尾空格；空白不可提交；与当前全部渠道名称忽略大小写比较，重名不可提交 |
| 网站域名 | 单行输入 | 网站小部件必填 | 空 | 仅用于主要网站标识；失焦与提交时执行第 5.2 节规范化与校验 |
| 界面语言 | 单选 | 是 | 自动 | 自动及八种固定语言，见第 5.3 节；不修改 Agent 回复语言配置 |
| 接待 AI Agent | 带头像与名称的单选 | 是 | 未选择 | 选择后展示头像与名称；创建候选范围与详情存在差异，见 Q01 |

名称和签名等文本长度没有可确认的上限，不在本文虚构字符数，统一列为 Q03。

| 操作 | 条件 | 系统行为与结果 |
|---|---|---|
| 添加网站／创建 | 点击主按钮 | 网站小部件先检查域名，再校验名称与 Agent；错误时保留表单，成功创建后关闭表单并展示接入结果弹窗 |
| 提交中 | 已开始提交 | 主按钮显示加载状态，避免重复提交；不生成多个渠道 |
| 域名错误 | 域名不合法 | 在域名字段旁显示错误，不创建实例 |
| 名称或 Agent 错误 | 必填缺失或名称重复 | 表单显示「请输入渠道名称」「渠道名称已存在，请使用唯一名称」或「请选择接待 AI Agent」 |
| 关闭弹窗 | 点击关闭入口且有未保存内容 | 确认「放弃未保存的内容？」；可放弃或继续编辑 |
| 取消 | 点击底部取消按钮 | 当前直接关闭，和关闭入口的保护逻辑不一致，见 Q02 |

### 3.3 创建结果与初始化

| 配置 | 网站小部件 | 聊天页面 |
|---|---|---|
| 启用状态 | 启用 | 启用 |
| 接入产物 | 独立安装代码 | 独立固定聊天 URL |
| 连接状态 | 未连接 | 不展示安装连接状态 |
| 允许域名 | 空，不自动填入网站域名 | 不适用 |
| 品牌名称 | 空，展示时回退渠道名称 | 同左 |
| 品牌 LOGO | 未上传，使用文字占位 | 同左 |
| 签名 | 有问题？我们随时为您提供帮助。 | 同左 |
| 主题色 | `#1c1f26` | 同左 |
| 悬浮图标 | 默认消息图标 | 不适用 |
| 桌面端／移动端展示 | 均开启 | 不适用 |
| 两端位置 | 均为右侧底部，分别维护 | 不适用 |
| 两端侧边距／底部间距 | 均为 24px，分别维护 | 不适用 |

创建成功不自动进入详情页。网站小部件展示「安装网站小部件」弹窗；聊天页面展示「与客户分享您的聊天页面」弹窗。关闭结果弹窗后保留已创建实例，不撤销创建。

## 4．渠道列表与日常管理

### 4.1 列表内容与查询

列表顶部为类型标题和新增入口。存在实例时展示名称搜索框；名称搜索忽略首尾空格与大小写，按包含关系匹配，清空后恢复完整列表。默认按创建时间倒序，每页 20 条并显示总数。

| 字段 | 展示规则 | 操作 |
|---|---|---|
| 渠道名称 | 类型图标与渠道名称 | 点击进入详情，默认打开基本设置 |
| 接待 AI Agent | Agent 头像与名称；关联对象缺失时显示「未配置」 | 仅展示，修改进入详情 |
| 创建时间 | 年月日及小时分钟 | 不因编辑配置而变化 |
| 状态 | 仅网站小部件展示「未连接／已连接」 | 不提供手动切换 |
| 启用状态 | 开关 | 立即执行启停流程，不需要额外点击保存 |
| 更多操作 | 编辑、删除 | 编辑进入详情；启用中的渠道禁用删除 |

无实例时显示该类型空态及创建入口；搜索无结果显示「没有找到匹配的渠道」，保留搜索框以便修改或清空。当前不提供状态筛选、Agent 筛选或批量操作。

### 4.2 启停规则

| 动作 | 前置条件 | 行为与结果 |
|---|---|---|
| 启用 | 已配置且存在的 Agent 已发布并正在接待 | 即时启用，列表与详情同步，反馈「渠道已启用」 |
| 启用失败 | Agent 缺失、未发布或未接待 | 保持停用，提示「请先配置已发布且正在接待的 AI Agent」 |
| 停用 | 渠道正在启用 | 二次确认；确认后立即停用，取消不改变状态 |
| 停用结果 | 已确认停用 | 禁止新的客户消息进入，保留历史会话；反馈「渠道已停用」 |

启停独立于详情分组保存。存在配置草稿时，启停不能代替保存草稿。启用检查是否应使用尚未保存的 Agent 选择，见 Q04。

**启用不等于可接待**：客户发送消息还需满足当前实际接待 Agent 可用、网站域名规则允许等条件；「已连接」也不能替代这些条件。

### 4.3 删除

仅停用实例可在列表更多菜单中删除。删除弹窗展示对象名称及历史保留说明，要求输入完整渠道名称；输入与原名称完全一致时「确认删除」才可用，空值、不一致和大小写差异均不能确认。

确认后从渠道列表移除实例，全部页数量同步更新，公开入口不再提供服务；历史会话保留。旧聊天 URL 显示渠道不存在，不因名称相同的新实例而恢复。详情页不重复提供删除入口。

## 5．配置渠道与保存规则

### 5.1 详情结构与分组草稿

详情顶部展示返回、渠道类型图标和渠道名称，右侧展示启用状态；网站小部件额外在启停之前提供「安装代码」。内容区由配置导航、配置表单和持续可见的预览组成。

| 类型 | 配置分组 |
|---|---|
| 网站小部件 | 基本设置、品牌外观、可见性与位置 |
| 聊天页面 | 基本设置、品牌外观、聊天链接 |

1. 每组独立维护未保存内容；修改后导航项出现未保存圆点，当前组「保存」「取消」可操作。
2. 切换组保留各组未保存内容；预览同时反映已有草稿，不要求先保存。
3. 保存仅校验并提交当前组；成功提示「当前分组已保存」，清除当前组标记，其他组草稿保留。
4. 取消恢复当前组最近保存值，提示「已恢复当前分组的最近保存配置」，不撤销其他组草稿。
5. 没有编辑操作时保存和取消禁用。修改后再手动改回原值的精确脏值比较未定义，不额外设定为强制行为。
6. 使用顶部返回时，有未保存内容须确认放弃或继续编辑；刷新、关闭浏览器时触发浏览器离开提醒。其他全局导航的拦截范围见 Q02。
7. 客户入口使用已保存配置。预览变化不代表对外配置已经生效。
8. 进入另一渠道详情时回到基本设置；详情对象不存在时显示「渠道不存在」及「返回渠道列表」。

### 5.2 基本设置与域名校验

基本设置字段顺序为渠道名称、网站域名（仅网站小部件）、界面语言、接待 AI Agent。初始值读取已保存配置。

渠道名称和 Agent 必填。详情 Agent 候选仅包含已发布且正在接待的对象，不提供额外的搜索输入框。更换后的关联仅用于新会话，当前会话仍保留原 Agent。保存名称时的重名处理见 Q03。

**网站域名规范**同时用于网站域名字段和允许域名单项输入：

| 输入情况 | 处理与示例 |
|---|---|
| 普通域名 | 接受 `www.example.com`；统一为小写主机名 |
| HTTPS 完整根地址 | 接受 `https://www.example.com/`，回显 `www.example.com` |
| 首尾空格、末尾域名点 | 去首尾空格；移除主机名末尾的点 |
| HTTP 地址 | 拒绝，提示「请输入 HTTPS 网站地址」 |
| 路径、端口、参数、片段或认证信息 | 拒绝；除根路径 `/` 外不接受路径；提示「网站地址不能包含路径、端口或参数」 |
| 通配符、IP、无点的主机名 | 拒绝，例如 `*.example.com`、`127.0.0.1`、`localhost` |
| 域名标签非法 | 标签为空、超 63 字符、首尾为连字符或含非法字符均拒绝；域名总长度不超过 253 字符 |
| 空网站域名 | 提示「请输入网站域名」，阻止创建或保存 |
| 其他格式错误 | 提示「请输入正确的网站域名，例如：www.example.com」 |

网站域名不是授权白名单。修改网站域名不自动更新允许域名，不改变渠道标识或安装代码。

### 5.3 界面语言

选项固定为：自动、简体中文、繁体中文、英语、越南语、泰语、高棉语、缅甸语、老挝语。默认自动；选择后关闭菜单，当前项保持选中标记；语言菜单点击外部或按 Esc 关闭。

固定语言用于客户界面文案，不修改 Agent 回复语言。管理端预览切换语言后重置预置消息与本次预览输入、附件及时间戳状态。

自动语言的目标为按环境确定客户界面语言，无法匹配时回退英语。但当前自动识别、部分语言的错误提示和管理预览存在不一致，详细列于 Q06；不能将「九个选项」等同于全部界面文案已经完整本地化。

### 5.4 品牌外观

| 字段 | 必填／默认 | 交互与保存规则 |
|---|---|---|
| 品牌名称 | 可空；初始为空 | 空时以渠道名称作占位和对客展示兜底，不把渠道名称写入品牌字段；手动填写后独立维护 |
| 签名 | 可空；默认「有问题？我们随时为您提供帮助。」 | 显示在品牌名称下方；清空后不显示，不作为实时在线状态 |
| 品牌 LOGO | 可空；初始无图片 | 点击图片区域上传或更换；已有图片时提供删除操作，删除后恢复文字占位 |
| 主题色 | 默认 `#1c1f26` | 颜色选择器和 HEX 输入框编辑同一值；保存仅接受 `#` 加六位十六进制字符 |

品牌 LOGO 和自定义悬浮图标使用相同上传限制：图片类型、单文件不超过 2 MB；非图片提示「仅支持图片文件」，超限提示「图片大小不能超过 2 MB」，读取失败提示重试。上传成功进入当前组草稿并刷新预览，仍需保存才作为对外配置。

主题色作用于聊天窗口相关区域及悬浮入口；前景文字与图标按背景明暗切换深浅色。非法 HEX 值阻止当前组保存，提示「请输入合法的 6 位 HEX 主题颜色」。后台工作台的品牌色不随渠道主题色改变。

## 6．网站小部件的展示与安装

### 6.1 允许域名

位于「可见性与位置」分组顶部，默认为空。空列表表示不限制展示域名；创建时填写的网站域名不会自动进入此列表。

| 操作／条件 | 结果 |
|---|---|
| 输入域名后按 Enter | 校验通过后添加为标签并清空输入；未保存前仅属本组草稿 |
| 输入错误 | 字段旁和反馈消息提示错误，不添加标签 |
| 输入重复域名 | 不重复添加，提示「该域名已添加」 |
| 点击标签移除 | 从草稿移除，保存后生效 |
| 移除最后一项并保存 | 恢复不限制域名 |
| 列表非空 | 当前匹配行为为所填域名本身及其下级子域名；例如 `example.com` 包含 `shop.example.com`，不包含 `otherexample.com` |
| 来源不匹配 | 客户端不展示对应历史消息、禁止发送，并提示当前网站未获授权 |

安装来源的可信判断、无来源时处理以及旧文档的主域名／`www` 规则尚需确认，见 Q07。不得将输入域名匹配能力描述为已完成安全授权机制。

### 6.2 悬浮入口与设备设置

| 字段 | 默认 | 可选值与行为 |
|---|---|---|
| 悬浮按钮图标 | 默认消息图标 | 三种预设消息图标，或上传自定义图片；单选，选中项明确标识 |
| 自定义图标 | 空 | 上传后选中自定义；图片按比例居中裁切并铺满圆形入口 |
| 恢复默认图标 | 自定义时出现 | 清除自定义图标草稿并选中默认消息图标，保存后生效 |
| 设备标签 | 桌面端 | 桌面端／移动端；切换配置对象，并同步切换预览设备 |
| 展示 | 两端均开启 | 分别控制该设备是否显示小部件；不改变渠道启用状态 |
| 按钮位置 | 两端均为右侧 | 左侧底部／右侧底部，分设备维护 |
| 侧边距 | 两端均为 24px | 0～100 的整数，表示距所选侧边距离 |
| 底部间距 | 两端均为 24px | 0～100 的整数，表示距底部距离 |

移动端与桌面端四个间距值及两个位置分别保存，修改一端不覆盖另一端。当前客户界面宽度小于 768px 时使用移动端配置，否则使用桌面端配置。

两端展示均关闭时允许保存，但提示「所有设备均已隐藏，客户将看不到网站小部件。」；隐藏设备的管理预览显示「该设备已隐藏网站小部件」。关闭展示不清空既有会话，不等于删除渠道。

### 6.3 安装代码与连接状态

创建成功或点击详情顶部「安装代码」时，打开「安装网站小部件」弹窗。弹窗展示该渠道代码、安装说明及「复制代码」；说明将代码放在网页 `</body>` 标签之前。关闭弹窗不修改渠道配置。

代码中的渠道标识固定，名称或外观修改不会生成新代码。当前不提供代码编辑、安装记录、安装检测按钮或开发文档跳转入口。

网站小部件列表初始为「未连接」，识别到渠道客户入口加载后更新为「已连接」。连接状态不与启停联动，也不因停止接待自动改为未连接。真实安装成功判据与离线回落见 Q08。

## 7．聊天页面的链接分享

### 7.1 创建后的分享弹窗

标题为「与客户分享您的聊天页面」，提供只读链接框、「复制链接」和「打开聊天页面」。说明链接可分享至新闻简报、网站和社交媒体。

复制成功反馈「聊天页面链接已复制」；打开操作在新标签页进入该渠道的独立聊天页面。复制失败的反馈见第 10 章，不能因权限拒绝仍误报成功。

### 7.2 详情中的聊天链接

「聊天链接」分组展示只读「聊天页面 URL」、复制图标按钮和「打开聊天页面」。无二维码、二维码下载、自定义域名或手动修改 URL 的字段。

链接绑定渠道标识，修改渠道名称、品牌、Agent 不改变链接。停用渠道后链接仍可打开，但不能发送客户消息；删除后显示渠道不存在。链接分组没有可编辑字段，不要求为了复制或打开先保存。

客户聊天页面使用独立全页聊天布局；管理端对应预览铺满右侧预览区域，不使用悬浮窗口和悬浮按钮。

## 8．管理端预览

### 8.1 预览目的与内容

管理员在配置时观察品牌、主题色及小部件展示效果。预览头部仅显示「预览」，安装代码入口位于详情顶部。预览不创建正式 Conversation，不写入收件箱，不验证 AI 回复效果。

| 区域 | 默认值与行为 |
|---|---|
| 品牌头部 | 跟随品牌名称、LOGO、签名和主题色草稿 |
| 初始消息 | 一条客服消息、一条客户消息；按所选语言展示预置文本 |
| 输入区 | 输入非空文本后，Enter 或发送按钮追加客户消息，清空输入 |
| 附件入口 | 选择文件后直接追加客户侧附件消息；支持重复选择同一文件 |
| 消息时间 | 默认隐藏；点击一条消息显示其时间，再次点击隐藏，切换消息仅显示当前一条时间 |
| 静音图标 | 可切换当前预览的通知开关状态；不修改客户的静音偏好 |
| 网站窗口 | 初始展开；收起后显示悬浮按钮，再次点击打开，保留当前预览消息 |
| 聊天页面 | 无收起入口，持续展示聊天区域 |

图片直接按比例显示，视频与音频提供播放控件，其他文件显示扩展名、名称和大小。新增消息及媒体加载完成后滚动至最新内容；长名称避免挤出容器。

### 8.2 预览状态与边界

配置组切换不会清空消息。改变界面语言、切换渠道或重新进入详情后恢复初始消息，并清除本次输入、附件和展开的时间戳。管理预览的附件展示不代表客户端放开格式白名单；客户端限制以第 9.3 节为准。

预览不自动回复，不提供清空会话按钮、表情面板或正式历史记录。预览中的静音交互不作为真实提示音投递验收依据。

## 9．客户咨询与会话流转

### 9.1 打开入口与可用性

网站小部件默认收起，按设备配置决定是否显示入口；点击后打开聊天窗口，点击收起关闭窗口但不结束会话。聊天页面直接展示完整聊天区域，不提供悬浮按钮。

| 区域 | 内容与规则 |
|---|---|
| 头部 | 品牌 LOGO 或文字头像、品牌名称或渠道名称兜底、非空签名、提示音开关；小部件额外提供收起 |
| 消息区 | 当前客户在当前渠道的连续消息，按日期分隔；当前日期展示为年月日格式 |
| 待发区 | 已选附件、发送中状态、错误及可重试操作 |
| 输入区 | 附件、表情、文本输入、发送按钮 |

渠道不存在时显示「聊天渠道不存在」及链接检查说明。渠道停用、实际接待 Agent 未发布或未接待时，输入与发送入口不可用并提示「当前客服暂不可用」。当前存在处理中会话时，以该会话的原 Agent 判断接待能力；没有当前会话时，以渠道当前绑定 Agent 判断。

### 9.2 文本与表情

| 操作 | 规则 |
|---|---|
| 发送文本 | 去首尾空格；无有效文本且无附件时禁止发送 |
| 发送快捷键 | Enter 发送，Shift + Enter 换行；输入法组合输入期间不触发发送 |
| 选择表情 | 点击表情图标打开面板；选择后替换当前选中文本或插入光标位置，关闭面板并回到输入框 |
| 关闭表情 | 点击面板外部收起，不改变已有输入 |
| 发送中 | 显示「正在发送…」，禁用输入及发送相关按钮，避免重复提交 |
| 离线 | 显示「网络异常，消息未发送」，保留可恢复内容，不因离线操作新建会话 |
| 失败重试 | 错误区提供重试，重发原失败内容；重复投递防护的完整保证见 Q09 |

正文不承诺原型之外的文本长度上限、富文本输入、撤回、编辑已发送消息或消息已读回执。

### 9.3 客户附件

支持按钮多选、粘贴文件和拖拽文件到输入区域。附件先进入待发区，点击发送后才成为客户消息，不因选择文件创建会话。待发附件展示文件名和图片缩略图或文件图标，可单项移除。

| 类型 | 允许扩展名 | 消息展示 |
|---|---|---|
| 图片 | `.jpg`、`.jpeg`、`.png`、`.webp`、`.gif`、`.heic` | 图片展示；浏览器解码失败的回退见 Q10 |
| 文档 | `.pdf`、`.doc`、`.docx`、`.txt` | 文件信息与下载链接 |
| 表格 | `.xls`、`.xlsx`、`.csv` | 文件信息与下载链接 |
| 演示文档 | `.ppt`、`.pptx` | 文件信息与下载链接 |
| 音频 | `.mp3`、`.wav`、`.m4a`、`.ogg` | 音频播放控件，受浏览器格式支持限制 |
| 视频 | `.mp4`、`.mov`、`.webm` | 视频播放控件，受浏览器格式支持限制 |

1. 单文件最多 20 MB；超过时拒绝该文件并提示，不清空其他合法文件。
2. 一次待发最多 5 个文件，包含之前已选文件。按顺序接收符合类型和大小要求的文件，达到剩余额度后不再接收；超额提示「每次最多上传 5 个文件」。
3. 白名单外文件拒绝并提示「不支持该文件格式」。客户端不接受压缩包、SVG、脚本或可执行文件；这与管理预览可展示普通文件的行为不同。
4. 待发文件有效期为添加成功后 24 小时；发送时排除已过期文件并提示重新上传。若同时有有效文本或附件，可继续发送有效内容。
5. 文本与附件允许一起提交，形成一条文本消息及各附件消息，归属同一 Conversation。
6. 上传进度、上传失败逐项重试、服务端文件真实性校验、正式存储清理及附件鉴权尚未闭环，见 Q10、Q13。

### 9.4 匿名身份、历史与新会话

当前匿名客户显示名称采用 `Visitor #` 加六位数字。不同渠道的客户消息不混合展示；同一客户在同一渠道的多个 Conversation 在客户侧以连续消息流展示。

| 场景 | 会话行为 |
|---|---|
| 仅加载入口、打开窗口、查看历史 | 不创建 Conversation |
| 无当前会话，首次成功发送有效客户消息 | 创建「处理中」Conversation，记录当前渠道及接待 Agent，写入客户消息 |
| 存在当前处理中会话 | 新消息继续写入该会话，保留原 Agent |
| 刷新或收起后重新打开 | 当前身份仍有效时恢复已有消息，不因打开动作额外创建会话 |
| 会话已关闭后成功发送新消息 | 创建新 Conversation，使用渠道当前 Agent |
| 渠道改绑 Agent | 不改写既有 Conversation 的 Agent，新会话使用新配置 |
| 原会话 Agent 不可用 | 当前会话禁止发送，即使渠道已改绑其他 Agent，也不提前改派 |

初次显示最近 40 条可见消息；向上滚动至顶部附近时每批追加最多 40 条更早消息，保持阅读位置。不同日期显示分隔；不提供独立历史会话列表或「加载更多」按钮。

当前无可见历史时展示按语言确定的欢迎文本；欢迎文本出现不等于已经生成 Conversation。该文本与 Agent 自定义欢迎语的整合、历史全部过期后的空态见 Q11。

匿名身份跨标签、跨设备或关闭浏览器后的恢复能力不作为已确认承诺。原文档的可信登录、匿名转登录自动关联及网站身份范围规则见 Q12。

### 9.5 超时、收件箱与历史保留

会话超时采用现有设置中的聊天超时开关与分钟数；开启时，从会话最近更新时间计算。超过时关闭当前 Conversation，并记录「会话因长时间无新消息自动结束」系统消息；关闭窗口或浏览器本身不是结束条件。

收件箱根据渠道标识关联会话，同时保留会话创建时的渠道名称、类型、Agent 与客户名称。渠道改名、改绑或删除不追溯改写历史归属。管理端预览消息不进入收件箱。

当前可确认「处理中 → 超时关闭」路径；「已解决」判定、后台独立计时、Agent 话术及跨日期统计不在本次重新定义，见 Q11、Q14。

原文档规定消息及附件保留六个自然月，当前可见消息按 183 天窗口处理，二者并不等价。保留期、附件实际清理及过期空态未冻结前，不将任一口径写成已完成的服务承诺，见 Q13。

### 9.6 未读与提示音

| 场景 | 预期行为 |
|---|---|
| 网站小部件收起后收到新 AI 消息 | 悬浮入口显示未读数，超过 99 显示 `99+` |
| 网站小部件展开但正在看旧消息 | 保留阅读位置，出现新消息提示；点击提示回到最新并清除未读 |
| 当前窗口位于消息底部 | 新消息追加并视为已读，不累积无意义未读 |
| 聊天页面处于后台标签 | 新 AI 消息使标题显示「(N) 品牌名称」；已读后恢复品牌名称 |
| 初始化或加载历史 | 不按新消息增加未读，不播放通知音 |
| 客户自身发送 | 不触发 AI 新消息提示音 |
| 客户切换静音 | 立即生效，按浏览器与渠道保存，默认开启声音；不影响文字未读提示 |

提示音为低音量短双段音效，浏览器禁止自动播放时不阻断聊天。没有管理员级「聊天设置」去覆盖客户偏好。多消息计数、后台已读时机与连续回复只响一次的准确行为存在核验缺口，见 Q15。

## 10．异常与一致性要求

以下要求区分当前明确反馈与待补齐的异常分支；待补齐项须经评审纳入研发验收，不能当作已经验证通过。

| 场景 | 页面与恢复要求 | 当前依据 |
|---|---|---|
| 表单必填或格式错误 | 阻止提交，保留输入，提示对应字段或表单错误 | 已有明确校验；创建／编辑差异见 Q01、Q03 |
| 主题色或边距非法 | 阻止当前组保存，保留草稿 | 已有校验与控件限制 |
| 图片非图片或超 2 MB | 拒绝新图片，保留原图与其他草稿 | 已有反馈 |
| 客户文件不合法或超限 | 拒绝该文件，保留合法文件 | 已有反馈 |
| 客户网络离线 | 不发送、不新增会话，保留内容及重试入口 | 已有分支；重试一致性见 Q09 |
| 渠道或 Agent 不可用 | 禁止发送，允许查看当前可访问历史 | 已有可用性判断 |
| 来源域名不匹配 | 历史不展示、发送禁止，提示未授权 | 已有匹配分支；可信来源见 Q07 |
| 渠道已删除 | 客户侧显示不存在，管理详情可返回列表 | 已有空态 |
| 列表加载失败 | 应保留查询条件并允许重试 | 当前没有完整失败态，待补齐 |
| 配置保存失败 | 应保留当前组和其他组草稿，允许重试，不提前反馈成功 | 当前缺少实际失败恢复分支，待补齐 |
| 剪贴板复制失败 | 应提示复制失败，不误报成功；原内容继续可见 | 当前未核对剪贴板结果，待补齐 |
| 多人编辑冲突 | 不应静默覆盖其他人的更新 | 原文档要求保留，冲突机制待确认 |
| 关联 Agent 在提交前变化 | 提交时应重新确认可用性，不能仅依赖下拉选项 | 创建、保存、启用行为不一致，见 Q01、Q04 |

新增渠道成功后，类型数量、列表记录及其状态须一致；保存分组后不能覆盖其他组尚未保存值。客户消息失败恢复、跨页面状态同步以及服务端幂等的实际实现方式由研发确定。

## 11．待确认事项与原文档规则承接

以下不是新增功能清单，而是原文档与当前产品之间尚需明确的边界。本文已经完整描述可确认的路径；涉及下表的验收不得直接标为通过。

| 编号 | 事项 | 已发现事实与差异 | 建议评审结论 |
|---|---|---|---|
| Q01 | Agent 候选与提交校验 | 创建下拉包含全部 Agent，详情仅含已发布且接待中的 Agent；创建默认启用却只校验是否选了 ID | 建议三处统一检查有效且可接待的 Agent；未确认前不宣称创建已过滤不可用 Agent |
| Q02 | 放弃修改保护 | 创建关闭入口会确认，底部取消直接退出；详情返回与浏览器刷新有保护，其他导航未统一拦截；未填表关闭也可能确认 | 确认是否统一按实际未保存修改拦截，避免不同退出路径结果不同 |
| Q03 | 名称和字符规范 | 创建检查全部渠道重名并裁剪空格；详情未检查重名且保留原输入；文本长度未明确 | 确认创建与编辑统一的重名范围、空格处理及长度限制 |
| Q04 | 未保存 Agent 与启用 | 详情启用判断读取草稿 Agent，但启停只保存启用状态 | 建议按已保存 Agent 校验；或先要求保存基本设置，避免启用依据与对外配置不一致 |
| Q05 | 删除、停用与现有消息 | 停用禁止发送、删除保留历史已明确；关闭中的请求与在途自动消息未定义 | 明确停用／删除时已发起请求的接受边界，不能据静态页面推断服务端结果 |
| Q06 | 语言识别与翻译完整性 | 自动识别未完整覆盖简体中文及多级回退；部分非中文语言的错误提示回退英语；预览自动时使用中文示例 | 确认自动识别优先级与支持范围；建议保留原文档的网站语言→浏览器→英语规则，但须补齐实现后验收 |
| Q07 | 域名匹配与授权 | 当前支持所填域名及所有子域；无来源信息时允许；原文档有主域名／www 归一和隔离要求 | 确认授权匹配范围与网站身份隔离分别如何定义；生产来源必须可信，不能用客户自报参数授权历史 |
| Q08 | 安装连接判据 | 当前入口加载即记已连接，不验证真实安装、可用 Agent 或来源；无失联回落 | 定义何种回执代表安装成功、是否需过期状态；保留无手动检测入口的既定范围 |
| Q09 | 失败重试一致性 | 已有离线与重试入口，但消息写入未按消息 ID 去重，重试后草稿与待发附件未统一清理 | 明确一次发送的唯一性和重试后输入恢复，避免成功重试后再次发送相同内容 |
| Q10 | 附件完整能力 | 有格式／大小限制及展示；缺少逐文件进度与读取失败恢复，图片放大和不支持格式回退未完整提供 | 保留原文档安全与权限约束；明确哪些展示与上传失败能力纳入本期补齐 |
| Q11 | 欢迎语、跟进与结束 | 当前为固定欢迎文本；并未完整串联 Agent 的欢迎、跟进、结束设置；全部历史过期时仍展示欢迎文本 | 不把固定文本当作完整 Agent 接待规则；确认是否沿用原文档话术衔接和过期空态 |
| Q12 | 客户身份 | 当前只可确认匿名及渠道内隔离；可信登录、跨设备、匿名转登录合并、网站间身份隔离没有完整当前路径 | 原文档相关要求保留待评审，不视为已取消，也不写作已完成；决定纳入本期还是独立后续需求 |
| Q13 | 留存与安全 | 原文档六个自然月与当前 183 天不一致；服务端临时附件清理、正式附件鉴权、实际类型验证无可核验证据 | 留存及安全要求不得静默放宽；确认统一时间口径和实际删除／失效机制 |
| Q14 | 状态、计时与统计 | 可确认超时关闭，无法据当前客户端保证页面离开后计时、已解决判定、跨日期统计 | 沿用收件箱最终规则，不新设已解决判断；单独核对后台计时和统计口径 |
| Q15 | 未读精确性 | 当前按最新 AI 消息变化累加，批量到达、后台自动清零、打开即清零存在边界差异 | 明确按消息数还是回复事件计数；按实际阅读范围清零，并验证同一回复只响一次 |
| Q16 | 通用失败与权限 | 保存失败、复制失败、并发冲突及真实权限未有完整可验路径 | 复用工作台能力，不新增渠道权限页面；补齐失败恢复后才作为交付通过项 |

原文档中「凭证须可验证且有时效」「不得仅凭用户自报 ID 读取他人历史」「附件须校验访问权限和真实类型」仍作为生产接入评审约束，不能因当前原型未覆盖而删去。本文不规定未经确认的接口、凭证字段或技术架构。

## 12．验收标准

本表是验收用例定义，不代表已经执行通过。带 Q 编号的用例须先确认对应规则；其余按正文执行。异常恢复不得通过显示成功提示替代真实操作结果。

| 编号 | 场景与操作 | 通过标准 |
|---|---|---|
| AC01 | 类型无实例／有实例 | 分别显示创建入口／管理入口和数量，停用实例仍计入数量 |
| AC02 | 创建网站与聊天页面 | 字段顺序正确；仅网站必填域名，类型不可切换，默认语言自动 |
| AC03 | 空名称、空 Agent、重复名称提交 | 不生成实例，保留输入并给出对应错误；重名忽略大小写与首尾空格 |
| AC04 | 输入 HTTPS 根地址、HTTP、路径、IP、通配符 | 合法地址规范化；非法输入阻止提交，错误位置正确 |
| AC05 | 创建成功 | 仅一个新实例，默认启用；弹出对应代码／链接结果，不自动跳详情 |
| AC06 | 关闭结果弹窗 | 实例仍存在；网站初始未连接，允许域名为空 |
| AC07 | 名称搜索与分页 | 忽略大小写的包含匹配，清空恢复；创建时间倒序，每页 20 条 |
| AC08 | 空列表与搜索无结果 | 两类空态不同，均有继续任务的路径 |
| AC09 | 进入详情 | 基本设置默认打开；网站与聊天页面分组正确，无已移除入口 |
| AC10 | 修改多个分组后保存其中一个 | 只保存当前组，其他组草稿和标记保留 |
| AC11 | 取消一个分组 | 仅该组恢复最近保存值，预览回退该组效果 |
| AC12 | 有草稿时顶部返回或刷新 | 可选择放弃或继续；其他退出路径待 Q02 |
| AC13 | 品牌名空值／手动填写／改渠道名 | 空值回退渠道名，手动品牌不随渠道名修改 |
| AC14 | 上传、更换、删除品牌 LOGO | 草稿与预览正确；非图片和超 2 MB 拒绝；保存后客户端使用新配置 |
| AC15 | 非法主题色 | 当前组不保存，其他草稿不丢失；合法六位 HEX 可保存 |
| AC16 | 添加、重复添加、移除允许域名 | 合法值规范化，重复不新增，最后一项移除后恢复不限制 |
| AC17 | 设置桌面与移动位置、边距 | 值分别保存，互不覆盖，预览随设备切换 |
| AC18 | 边距 0、100、负数、超 100、小数 | 边界值可配置；非法值不能作为最终整数配置保存 |
| AC19 | 两端均隐藏 | 可保存并提示；对应设备入口隐藏，不删除会话 |
| AC20 | 自定义图标与恢复默认 | 图片铺满圆形入口；恢复后使用默认消息图标 |
| AC21 | 复制安装代码与聊天链接 | 复制内容与当前渠道一致；复制失败验收依 Q16 |
| AC22 | 编辑名称后访问旧代码／URL | 仍指向同一渠道；改绑只影响新会话 |
| AC23 | 预览发送文字、图片、视频、音频、普通文件 | 正确展示并滚动，不自动生成 AI 回复，不写入收件箱 |
| AC24 | 点击预览消息、切换语言 | 时间戳可切换且仅一条显示；换语言重置预览消息及附件 |
| AC25 | 预览小部件收起和展开 | 入口与窗口切换，保留当前消息；聊天页无此入口 |
| AC26 | 启用缺失或不可接待 Agent 的渠道 | 阻止启用并提示；草稿场景依 Q04 |
| AC27 | 停用时取消／确认 | 取消不变；确认后列表详情一致，客户不能发新消息 |
| AC28 | 删除启用渠道／输入不匹配名称 | 启用时不可删除；停用后名称完全匹配才可确认 |
| AC29 | 删除成功 | 列表与计数更新，旧入口不可用，历史会话保留 |
| AC30 | 客户仅打开、选择附件但不发送 | 不创建 Conversation |
| AC31 | 首次成功发送及再次发送 | 首次创建一条处理中会话，后续消息进入同一会话 |
| AC32 | 渠道改绑 Agent | 旧会话保留原 Agent；关闭后新消息使用新 Agent |
| AC33 | 开启超时并到期 | 当前会话关闭并有系统消息；下一条成功消息新建会话 |
| AC34 | 空文本、Enter、Shift + Enter、中文输入法 | 空内容无附件不能发；发送与换行正确，输入法确认不误发 |
| AC35 | 表情插入 | 在光标或选区处插入，保留其余文本并恢复焦点 |
| AC36 | 客户文件 20 MB 边界、超过上限、禁止格式 | 合法边界可接收；超限／不支持文件拒绝，其他合法文件保留 |
| AC37 | 已有待发文件再选择超过额度 | 总数最多 5，按剩余额度接收并提示，不覆盖已有文件 |
| AC38 | 待发附件超过 24 小时 | 过期附件不发送，提示重传，有效内容按规则继续 |
| AC39 | 离线发送、恢复后重试 | 离线无新会话且可恢复内容；重试不重复写入及清理行为依 Q09 |
| AC40 | 超过 40 条历史向上滚动 | 分批加载并保持位置，跨日期有分隔 |
| AC41 | 新 AI 消息、客户消息、历史初始化 | 仅新 AI 消息触发通知；精确计数与后台标签清零依 Q15 |
| AC42 | 静音、刷新同渠道 | 偏好保持，文字未读不受静音影响 |
| AC43 | 域名不匹配 | 不展示历史且不可发送；可信来源及子域规则依 Q07 |
| AC44 | 九种语言选项 | 可选项完整、固定语言不改 Agent 配置；识别与全量翻译验收依 Q06 |
| AC45 | 身份、数据留存、附件授权、已解决判定 | 依 Q10～Q14 单独验收，不以配置页操作正常代替后台业务验证 |
