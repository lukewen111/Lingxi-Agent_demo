# 网站小部件与聊天页面原型覆盖规则

本文件记录产品评审中对 `web_widget_chat_page_v1_prd.md` 的已确认覆盖项。发生冲突时，以本文件为准。

- 网站小部件与聊天页面详情不展示「聊天设置」。
- 聊天页面不展示二维码。
- 安装代码弹窗不展示手动检测安装入口；列表状态由原型自动判断。
- 网站域名为必填标识；允许域名不自动带入网站域名，留空表示所有域名均可显示。
- 桌面端与移动端位置、侧边距和底部间距独立配置。
- 管理端预览仅模拟客户发送消息，不自动生成 AI 回复，不提供清空会话按钮。
- 正式客户侧消息通过统一状态进入收件箱；首次成功发送客户消息时创建会话。
- 悬浮入口未读与消息提示音仅由新 AI 消息触发；历史加载、客户发送和初始化不触发。
- 聊天页面标题在后台收到新 AI 消息时显示未读数量；读完后恢复品牌名称。
- 客户侧静音状态按浏览器和渠道保存，默认开启声音。
